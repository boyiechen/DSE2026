SMM: The Mechanics and the Mess

Simulated Method of Moments 的統計原理很短：用加權距離比較真實資料與模型模擬出的 moments。 真正困難的是把經濟模型、moment selection、identification、numerical optimization 與 verification 接成一條不會默默出錯的估計鏈。

Economic model \(\theta \to g(k,z;\theta)\)

參數先決定 policy function，不能直接跳到 moments。

Simulation policy \(\to\) fake panel

固定 random draws，讓參數變化而非抽樣雜訊推動 objective。

Estimation fake moments \(\approx\) data moments

用 inverse covariance 衡量各方向的統計距離。

Credibility identify, test, verify

optimizer 回傳數字不代表參數被識別，也不代表程式正確。

一句話掌握 SMM

投影片 pp.14-17 的簡單精神，也是後面所有技術細節的共同起點。

SMM = 用模型產生假資料，再找出讓假資料統計量最像真實資料統計量的參數。

如果模型直接給得出 likelihood 或解析 moment condition，就用 MLE 或一般 GMM； SMM 的價值出現在 \(\theta\) 到資料分布之間必須經過 Bellman equation、policy function 或 equilibrium，無法寫成 closed form，但仍然可以模擬。

真實資料 計算 \(\widehat m_D\)
猜一組 \(\theta\) 解 dynamic model
模擬資料 計算 \(\widehat m_S(\theta)\)
比較 moments \(\widehat g_n(\theta)=\widehat m_D-\widehat m_S(\theta)\)
調整參數 最小化加權距離

Econometrics

選擇正定的 \(W\)，最小化 \(\widehat g_n(\theta)'W\widehat g_n(\theta)\)。這一部分本質上是 GMM。

Economics

決定哪些 moments 真正回應研究問題，並解釋每個 parameter-moment comparative static。

Engineering

確保 solver、simulator、moment code、optimizer 與 inference 沒有各自看似合理的 silent failure。

這門課的核心立場是：今天解模型與寫 simulator 已相對便宜，但「程式能跑」和「估計可信」 仍是完全不同的標準。AI 可以加速 coding、parallelization 與 testing，研究者仍須負責 question、moments、identification 與經濟合理性。

1

從投資模型到模擬資料

pp.7-12：SMM 不是直接模擬 moments，而是先解出行為規則。

1.1 經濟環境

風險中立經理人在離散時間、無限期模型中選擇投資。當期 shareholder cash flow 為

\[ e(k,I,z)=\pi(k,z)-I,\qquad \pi(k,z)=zk^\alpha,\quad \alpha<1, \] \[ k'=(1-\delta)k+I. \]

\(k\) 是已安裝資本，\(I\) 是當期投資，\(\delta\) 是折舊率，\(z\) 是遵循 \(q(z'|z)\) 的 Markov profitability shock。報酬遞減 \(\alpha<1\) 防止企業無限擴張。

以 \(I=k'-(1-\delta)k\) 代回，可以直接把控制變數寫成明期資本：

\[ V(k,z)=\max_{k'}\left\{ zk^\alpha-\big[k'-(1-\delta)k\big] +\frac{1}{1+r}\int V(k',z')\,dq(z'|z) \right\}. \]

Value function \(V(k,z)\)

回答「企業處在 \((k,z)\) 時值多少錢」。較高資本與較高生產力通常提高 firm value。

Policy function \(k'=g(k,z;\theta)\)

回答「處在 \((k,z)\) 時選擇多少明期資本」。它才是模擬資料時真正反覆呼叫的行為預測。

為什麼投影片中的 policy function 對 \(k\) 幾乎是水平線？

這個極簡模型沒有 convex adjustment costs；當期既有資本主要透過 \((1-\delta)k\) 形成已給定的資源。選擇最適 \(k'\) 時，關鍵是目前 \(z\) 對未來 \(z'\) 的預測與 future marginal value，因此相同 \(z\) 下的 target capital 可以幾乎不依賴目前 \(k\)。加入 adjustment costs 後，投資會更平滑，\(g(k,z)\) 通常會明顯依賴 \(k\)。

1.2 模擬就是反覆執行 policy

  1. 指定初始狀態 \((k_{i0},z_{i0})\)。
  2. 用 \(k_{i,t+1}=g(k_{it},z_{it};\theta)\) 決定明期資本。
  3. 依 \(q(z_{t+1}|z_t)\) 與預先抽好的 random shock 產生 \(z_{i,t+1}\)。
  4. 對許多 firms、許多 periods 重複，並丟棄 burn-in observations。
  5. 從模擬 panel 建立與真實資料完全相同的變數與 moments。

因此 structural parameter \(\theta\) 並不直接對應一個 moment；它先改變 Bellman problem，再改變整張 policy surface，接著改變 simulated paths，最後才改變 moments。 這條長映射正是 closed-form estimation 困難、也正是 SMM 有用的原因。

2

為什麼需要 simulation estimator？

pp.14-17：當 restriction 存在但無法解析寫出時，用 simulation 評估它。

2.1 從一個故意繞遠路的 mean estimator 看全部方法

若 \(y_i\) i.i.d. 且只想估計 \(\mu\)，一般 method of moments 直接使用 \(\E[y-\mu]=0\)，得到 \(\widehat\mu=\bar y\)。SMM 可以故意採取更麻煩的做法：

  1. 給定候選 \(\mu\)，模擬一組平均數為 \(\mu\) 的資料並算出 \(\widehat\mu_s\)。
  2. 重複 \(S\) 次，令 \(\widetilde\mu(\mu)=S^{-1}\sum_s\widehat\mu_s\)。
  3. 選擇讓 \(\widetilde\mu(\mu)-\bar y\) 最接近零的 \(\mu\)。

這裡因為 closed form 已知，所以 simulation 是浪費；但若把「生成 mean-\(\mu\) 的隨機數」 換成「用 \(\theta\) 解出並模擬 dynamic model」，同一邏輯就變得有價值。

何時不必用 SMM？

restriction 可解析計算、likelihood 可可靠評估，或 sufficient statistics 已知時，直接 GMM/MLE 通常更精確、更便宜。

何時適合用 SMM？

模型可解、可模擬，但 likelihood 或 parameter-to-moment mapping 因動態決策、異質性或 equilibrium 而難以積分時。

選擇 SMM 不是因為模型「很 structural」。

真正判準是研究問題是否需要一個可做 counterfactual 的完整模型，以及模型 implied restrictions 是否只能透過 simulation 評估。先問問題，再決定是否值得承擔 structural estimation 的識別與工程成本。

3

Objective function：SMM 是 simulation-based GMM

pp.19-23：把「假資料看起來像真資料」寫成可估計的統計問題。

3.1 Data moments 與 simulated moments

令 \(w_i\) 是真實資料 observation，\(y_{is}(\theta)\) 是第 \(s\) 次 simulation 的第 \(i\) 個 observation，\(g(\cdot)\) 回傳要匹配的 \(m\times1\) 統計向量。定義

\[ \widehat m_D=\frac{1}{n}\sum_{i=1}^{n}g(w_i), \] \[ \widehat m_S(\theta) =\frac{1}{S}\sum_{s=1}^{S} \left[\frac{1}{n}\sum_{i=1}^{n}g\big(y_{is}(\theta)\big)\right], \] \[ \widehat g_n(\theta)=\widehat m_D-\widehat m_S(\theta). \]

若模型與參數正確，population 中兩邊應產生相同 moments，故 \(\E[\widehat g_n(\theta_0)]=0\)。估計量是

\[ \widehat\theta =\argmin_{\theta\in\Theta}Q_n(\theta), \qquad Q_n(\theta)=\widehat g_n(\theta)' \widehat W_n\widehat g_n(\theta), \]

\(\widehat W_n\) 必須 positive definite。它定義 moment error 空間中的距離： 哪些差異統計上嚴重、哪些差異大多只是資料本身估得不準。

3.2 為什麼「完全相同的 calculations」是統計條件？

SMM 比較的是同一個 estimand 在 data 與 model 下的值。只要兩邊的 variable definition、 trimming、fixed effects、winsorization、sample selection、frequency aggregation 或 regression specification 不同，\(\widehat g_n(\theta)\) 就不再代表模型 miss，而混入 measurement mismatch。

最佳實作：只寫一個 moment-calculating function。

同一個函數分別接受 real dataset 與 simulated dataset。兩套「看起來一樣」的程式碼會隨時間 drift，是最常見且不會造成 crash 的錯誤來源。

3.3 模擬樣本要多大？

投影片引用 Michaelides and Ng (2000) 的 finite-sample 經驗：總模擬樣本 \(Sn\) 約為真實樣本的十倍往往有良好表現。這是有用的起點，不是 universal law； 最終仍要用不同 \(S\)、不同 panel length 與 Monte Carlo 檢查 estimates 是否穩定。

4

推論：linearization 與 simulation noise

pp.24-37：複雜 argmin 的一階近似，決定 standard errors 與 specification tests。

4.1 用統一記號避開 transpose 混亂

以下定義 moment Jacobian

\[ D_0 \equiv \left. \frac{\partial \E[\widehat g_n(\theta)]}{\partial\theta'} \right|_{\theta=\theta_0}, \qquad D_0\in\mathbb R^{m\times k}. \]

\(m\) 是 moments 數量，\(k\) 是 parameters 數量。投影片有時以 \(G=D'\) 表示 \(k\times m\) 矩陣；只要全程維度一致，兩種寫法完全相同。

4.2 FOC linearization 的直覺

在 \(\theta_0\) 附近， \(\widehat g_n(\widehat\theta) \approx\widehat g_n(\theta_0)+D_0(\widehat\theta-\theta_0)\)。 將它代入 quadratic objective 的 FOC 並解出參數誤差：

\[ \sqrt n(\widehat\theta-\theta_0) \approx -\big(D_0'WD_0\big)^{-1}D_0'W \sqrt n\,\widehat g_n(\theta_0). \]

左邊原本是 complicated optimizer 的輸出；右邊把它改寫成 moment sampling errors 的線性函數。這個線性 loading 就是 estimator 的 influence-function skeleton。

4.3 \((1+1/S)\) 從哪裡來？

moment discrepancy 同時包含兩個獨立誤差來源：

Data sampling error

真實 moments 的 variance 與 \(1/n\) 成正比。

Simulation error

平均 \(S\) 個、各長度 \(n\) 的 simulated samples 後，variance 與 \(1/(Sn)\) 成正比。

\[ \frac{\Lambda}{n}+\frac{\Lambda}{Sn} =\frac{1}{n}\left(1+\frac1S\right)\Lambda. \]

若使用 efficient weight \(W=\Lambda^{-1}\)，則

\[ \operatorname{Avar}(\widehat\theta) = \frac{1}{n}\left(1+\frac1S\right) \big(D_0'\Lambda^{-1}D_0\big)^{-1}. \]
固定 \(S\) 仍可 asymptotically normal。

每個 simulated panel 的長度隨 \(n\) 增加，simulation error 仍以 \(n^{-1/2}\) 收斂；固定 \(S\) 只是留下 \((1+1/S)\) 的效率成本。 例如 \(S=10\) 讓 variance 比無 simulation noise 時多 10%，而非讓 estimator 不一致。

4.4 Numerical Jacobian

由於 moments 來自 simulation，通常沒有解析 derivative。對 parameter \(j\)：

\[ \frac{\partial \widehat g_{n,\ell}(\widehat\theta)} {\partial\theta_j} \approx \frac{ \widehat g_{n,\ell}(\widehat\theta+h_je_j) - \widehat g_{n,\ell}(\widehat\theta-h_je_j) }{2h_j}. \]

\(h_j\) 太小

兩次 objective 的真實差異小於 numerical 或 simulation noise，得到的是 noise derivative。

\(h_j\) 太大

局部線性近似失效，產生 truncation error，無法代表 estimate 附近的 sensitivity。

1% of estimate 可當初始值，但正確做法是對每一組 parameter-moment 畫 \(\widehat g_\ell(\widehat\theta+he_j)\) 對 \(h\) 的 stability plot，尋找 slope 穩定區間。 計算左右差分時必須使用相同 random draws。

4.5 Overidentification 與 individual moment errors

若 \(m>k\) 且 \(W=\Lambda^{-1}\)，SMM 的 \(J\)-statistic 為

\[ J =\frac{nS}{1+S}Q_n(\widehat\theta) \overset{d}{\longrightarrow} \chi^2_{m-k}. \]

在 deliberately simplified 的 structural model 中，樣本夠大時常會 reject。 這不表示 test 沒用；它把問題從「模型是否 literally true」轉向「哪些 moments 沒有 fit， 而這些 miss 揭示模型少了什麼 channel」。除了 aggregate \(J\)，也應報告 individual moment errors 與對應 \(t\)-statistics。

4.6 Indirect inference

Indirect inference 不是另一套完全不同的機器。它把 \(g(\cdot)\) 換成 auxiliary model 的估計係數，例如 regression slopes、VAR coefficients 或 probit coefficients。 這些係數本身仍是資料 moments 的函數，因此 objective、weighting、IF covariance 與 verification 原理都相同。

5

Weight matrix 與 influence functions

pp.39-56：如何衡量多種統計量之間的聯合距離。

5.1 Weight matrix 到底在做什麼？

若兩個 moments 單位、sampling precision 與 correlation 不同，raw squared errors 不能直接相加。設資料 moment estimator 的 asymptotic covariance 為 \(\Lambda\)，efficient choice 是

\[ W=\Lambda^{-1}. \]

它會 downweight noisy directions，並避免把高度 correlated moments 當成兩份獨立資訊。 在這個 SMM setup 中，simulation covariance 在真值處只是多一個 scalar \((1+1/S)\)，不改變最適權重的相對方向，所以 \(\Lambda\) 可完全由真實資料離線計算。

選擇 實際含義 問題
\(W=I\) 最小化 raw moment errors。 機械地偏重數值尺度大的 moments，換單位就可能改變估計。
diag\((1/\widehat m_j^2)\) 最小化 percentage errors。 反向偏重接近零的小 moments，仍是任意尺度規則。
diag\((1/\widehat\Lambda_{jj})\) 依個別 moment precision 加權。 忽略跨 moments covariance，可能重複計算同一方向資訊。
\(\widehat\Lambda^{-1}\) 使用完整 clustered covariance。 需要穩定、positive-definite 的 covariance estimate，但統計上最有根據。

5.2 Influence function：把 estimator 攤回 observations

若某統計量 \(\widehat\tau\) 可以線性化為

\[ \sqrt n(\widehat\tau-\tau_0) = \frac{1}{\sqrt n}\sum_{i=1}^n\phi_\tau(w_i) +o_p(1), \qquad \E[\phi_\tau(w_i)]=0, \]

則 \(\phi_\tau(w_i)\) 是 observation \(i\) 對 estimate 的一階貢獻。 原本「mean 和 regression slope 的 covariance 怎麼算」這類複雜問題， 會變成「兩欄 observation-level contributions 的 inner product」。

Mean

\(\phi_{\mu,i}=z_i-\widehat\mu\)。離平均越遠的 observation，對 mean 的推動越大。

Variance

\(\phi_{\sigma^2,i}=(z_i-\bar z)^2-\widehat\sigma^2\)。極端 observations 推高 variance。

OLS slope

\(\phi_{\beta,i}=(n^{-1}\sum x_i'x_i)^{-1}x_i'u_i\)，就是 robust sandwich 的 observation-level summand。

5.3 Stacking：一個 \(n\times m\) 矩陣解決 joint covariance

把每個 matched statistic 的 sample IF 放成一欄：

\[ \Phi= \begin{bmatrix} \phi_{11}&\phi_{12}&\cdots&\phi_{1m}\\ \phi_{21}&\phi_{22}&\cdots&\phi_{2m}\\ \vdots&\vdots&\ddots&\vdots\\ \phi_{n1}&\phi_{n2}&\cdots&\phi_{nm} \end{bmatrix}. \]

兩種常見的 scaling convention 要分清楚：

\[ \widehat{\operatorname{Avar}} \big(\sqrt n\,\widehat m_D\big) =\frac{\Phi'\Phi}{n} \equiv\widehat\Lambda, \] \[ \widehat{\Var}(\widehat m_D) =\frac{\Phi'\Phi}{n^2} =\frac{\widehat\Lambda}{n}. \]

兩者只差整體 scalar \(n\)，不改變 SMM argmin；但寫 standard errors 與 \(J\)-test scaling 時必須明確說自己使用哪一個 convention。

5.4 Clustering

若 observations 在 firm \(c\) 內相關，先把同一 cluster 的 IF rows 加總： \(\widetilde\phi_c=\sum_{i\in c}\phi_i\)，再計算

\[ \widehat{\Var}(\widehat m_D) =\frac{1}{n^2}\sum_{c=1}^{C} \widetilde\phi_c'\widetilde\phi_c. \]

Firm clustering 容許 firm 內 serial dependence；time clustering 容許同一期 cross-sectional common shocks。若兩者都重要，需 two-way clustering。資料不是 i.i.d. 時， 不能只在最後 parameter SE 補救；資料 moments 的 covariance 一開始就必須反映 dependence。

5.5 不同 samples 與 frequencies

  • 獨立資料來源的 moments：joint covariance 為 block diagonal。
  • 部分 observations 重疊：對不存在的 observation-moment pair 補零後 stack。
  • aggregate time-series 與 panel moments 共用期間：依 time cluster 以保留共同 shocks。
  • 只有文獻提供的 standard errors、沒有 covariance：worst-case procedures 是最後手段；先設法重建 IF stack。
6

Identification：moments 是否真的釘得住 parameters？

pp.58-67：optimizer 的唯一答案可能只是演算法答案，不一定是經濟上的唯一答案。

6.1 這裡的 identification 不是 causality

Structural identification

population objective 是否只在真實 \(\theta_0\) 有唯一 minimum？它是 parameter-to-distribution mapping 的唯一性問題。

Causal identification

某個 empirical variation 是否能隔離 treatment 對 outcome 的 causal effect？它是 counterfactual comparison 的可信度問題。

Exogenous variation 對 causal claim 通常必要，但不自動識別偏好、固定成本、資訊精度等 structural primitives；後者仍需模型把 observables 映射回 parameters。反過來，某些 structural parameters 可以靠 distributional shape、dynamic transition 或跨 moments restrictions 識別，而不必依賴自然實驗。

6.2 Global 與 local identification

\[ \text{Global:}\qquad \E[\widehat g_n(\theta)]=0 \iff \theta=\theta_0, \] \[ \text{Local:}\qquad \rank(D_0)=k. \]

Global identification 排除遠處另一組 observationally equivalent parameters； local full rank 只保證 \(\theta_0\) 附近沒有某個 parameter combination 能在一階上完全不改變 moments。 非線性 simulation model 很難解析證明 global uniqueness，因此實務上要累積證據，而不是把 full-rank Jacobian 當成完整證明。

6.3 Moment selection 的經濟學

最理想的教科書敘事是「moment 1 identifies parameter 1」，但若真的一對一， 往往不需 SMM。現實中每個 parameter 影響許多 moments；關鍵是不同 parameter 在 moment space 中產生不同方向，而非只是「moment 數量至少等於 parameter 數量」。

每一欄至少要有 moments 對該 parameter 明顯反應；各欄還要有不同 pattern。 若兩欄成比例，資料只能識別兩個 parameters 的某個 combination。若整欄近零， objective 對該 parameter 幾乎平坦。

因此估計前應 sweep 每個 parameter，畫出每個 simulated moment 的 comparative statics。 好的關係通常 steep、穩定、最好 monotonic，且能以模型機制解釋。例如 persistence parameter 應主要改變 autocorrelation，而 volatility parameter 應明顯改變 variance； 若圖形方向令人意外，先理解或修正模型，不要交給 optimizer 掩蓋。

6.4 四層 identification diagnostics

Comparative statics

看完整 parameter range，檢查 monotonicity、nonlinearity 與可能的遠端第二組解。

Standard errors

巨大 SE 常表示 moments 對某方向反應太弱，但也可能來自 noisy numerical derivative。

Jacobian rank

rank deficiency 是 local underidentification 的直接警訊；也要查看 singular values 與 condition number。

Repeated searches

不同起始值到不同 minima，可能表示 local minima、coding bug 或 global nonidentification。

6.5 Andrews-Gentzkow-Shapiro sensitivity

parameter estimate 對 estimated data moments 的局部 sensitivity 為

\[ \mathcal S = -\big(D'WD\big)^{-1}D'W, \qquad \mathcal S\in\mathbb R^{k\times m}. \]

\(\mathcal S_{j\ell}\) 表示 data moment \(\ell\) 小幅上升時 parameter \(j\) 會移動多少。 乘上 \(\sqrt{\Lambda_{\ell\ell}}\) 可把「一單位 moment」改成「一個 sampling-standard-deviation 的 moment shock」，較容易跨 moments 比較。這個診斷同時反映 gradient steepness 與 moment precision。

敏感度圖也可能只是 step-size 圖。

\(\mathcal S\) 完全依賴 numerical \(D\)。若 derivative step 太小，heatmap 中的大數、符號翻轉 或近零欄位可能來自 simulation noise，而不是 economics。必須先通過 Jacobian stability checks。

7

SMM 作為 estimation engineering project

pp.69-82：公式簡單，但六個能 silent-fail 的模組必須被分開設計。

7.1 模組化 architecture

Data layer moments + \(\widehat W\)
Solver \(\theta\to V,g\)
Simulator \(g+\) shocks \(\to\) panel
Moments same function as data
Optimizer \(\min Q_n(\theta)\)

推論模組再使用 estimates、\(\widehat\Lambda\) 與 numerical \(D\) 產生 SE、\(J\)-test 和 sensitivity diagnostics。每一個 link 應有獨立 interface、unit test 與 log； 不要把整個 estimator 寫成無法單獨檢查的 black box。

7.2 固定 random numbers 的真正理由

\[ X_r=(aX_{r-1}+c)\bmod M. \]

pseudo-random draws 是 seed \(X_0\) 決定的 deterministic sequence。估計時應在外部先抽好所有 shocks，之後每一次 objective evaluation 都傳入同一陣列。這是 common random numbers： 比較 \(Q(\theta_a)\) 與 \(Q(\theta_b)\) 時，差異主要來自 parameters，而不是兩批不同 draws。

以下做法都會讓 objective function 抖動：

在 simulation loop 內重新 seed、用系統時鐘 seed、或讓 thread scheduling 決定 random stream。 optimizer 會追逐 simulation noise，仍可能回報「converged」與一組看似正常的 estimates。

7.3 Optimizer selection

SMM objective 通常沒有可靠 analytic gradient，可能不平滑且有 local minima。單次 local search 或預設參數的 Nelder-Mead 不足以建立 global minimum 的可信度。投影片建議考慮 simulated annealing、particle swarm、differential evolution，或 Tiktak 類 global-plus-local strategy。

Global exploration

廣泛搜尋 parameter bounds，避免只在某個初值附近找到局部解。

Multiple starts

不同 initial guesses 應收斂到相同 estimate 與 objective value。

Local refinement

global search 找到 promising basin 後，再用 deterministic local method 精修。

演算法沒有 global-minimum certificate。若不同 starts 得到不同答案，可能是 local minima、 bounds 不適當、underidentification、simulation noise 或 code error，不能只挑 objective 最低的一次。

7.4 先手動 calibration，再 optimization

手動改變 parameters 並觀察 moments，會迫使研究者理解 model mechanism、找出有辨識力的 moments、 發現 misspecification，並取得合理 starting values。optimizer 只能自動化已定義的 criterion， 無法告訴你某個經濟參數雖能 fit data 卻荒謬。

7.5 Model complexity 的成本轉移

AI 讓新增一個 state、friction 或 parameter 的 coding cost 下降，但 complexity 並未消失， 而是轉成 identification、interpretability、runtime 與 verification cost。可靠流程是： simple model \(\to\) 驗證 \(\to\) 診斷 miss \(\to\) 加入直接回答研究問題的 feature \(\to\) 再驗證。

7.6 Speed 與 heterogeneity

Speed

一次 estimation 可能解模型約 50,000 次。先用透明 prototype 驗證，再移植 inner loop 至 Julia/C/C++/Fortran 或平行化；新舊 solver 應在相同 inputs 下達到 machine-precision agreement。

Agent heterogeneity

標準 SMM model 往往沒有 discrete-choice error 提供 flexible heterogeneity。需用 firm/time FE、 sample splits 或明確的 type distribution 處理，而且對 simulated data 執行完全相同的 demeaning。

Verification：如何相信一個不會 crash 的錯誤程式？

pp.84-91：structural estimation 的 bug 往往只把 0.61 變成 0.43。

8.1 Silent-failure field guide

Failure 表面上為何合理 檢查方式
Timing mismatch solver 與 simulator 各自都能跑，但一邊讓 \(k_t\) 當期 productive，另一邊從 \(t+1\) 才 productive。 寫 timing spec；用手算的短路徑逐期比對。
Moment mismatch data 用 logs，simulation 用 levels；或只有一邊 demean。 一個 moment function；保存 intermediate transformed variables。
Burn-in error 初始狀態影響被誤認為 stationary distribution 的模型預測。 增加 burn-in，確認 moments 不再改變。
Random-stream error 每次 evaluation 都產生合理 panel，但 objective 無法平滑比較。 hash 預抽 shock array；每次 evaluation 驗證相同。
Wrong clustering point estimates 正常，只有 uncertainty 與 weights 被扭曲。 依資料 dependence structure 設計 cluster，與簡單 closed forms 對照。

8.2 Link-by-link test battery

Solver test

關閉 adjustment costs、taxes 等 frictions，與可解析的 frictionless solution 比到 machine precision。

Simulator test

模擬大 panel，逐期確認 choices 真的等於 policy function 在當期 states 的輸出。

Moment test

用人工構造的小資料檢查 mean、variance、FE、trimming 與 regression coefficients。

Weight test

IF code 先對 mean 與 OLS sandwich closed form；檢查 \(\widehat\Lambda\) symmetric positive definite。

Inference test

畫 Jacobian step-size stability plots，並用 alternative steps 驗證 SE 與 sensitivity 不翻轉。

Optimizer test

記錄完整 path，從多個 starts 搜尋，並在 estimate 附近畫 objective slices。

8.3 End-to-end Monte Carlo

  1. 在已知 \(\theta_0\) 下由模型模擬一份 fake dataset。
  2. 把它當成真資料，跑完整的 moments、weights、optimizer 與 SE pipeline。
  3. 檢查 \(\widehat\theta\) 是否回復 \(\theta_0\)。
  4. 重複 \(M\) 次，比較 across-replication SD 與平均 reported SE。
  5. 檢查 nominal confidence intervals 的 empirical coverage。
這是最有價值的完整測試。

單次 parameter recovery 驗證 point-estimation pipeline；多次 Monte Carlo 的 SD 與 coverage 進一步驗證 inference。若連模型自己生成的資料都無法回復已知真值，不應解讀 real-data estimates。

8.4 Babysit estimation

每次 objective evaluation 都應 log parameter vector、objective value、simulated moments、 moment errors、solver status 與 seed identifier。parameter 長期貼著 bound、劇烈跳動或只有少數 moments 主導 objective，都是 identification、model misspecification 或 bug 的訊號。 Algorithmic convergence 只表示停止規則成立，不表示收斂到真值。

8.5 與 AI 協作的責任分工

  • 先寫 human-readable spec：variable definitions、timing、sample filters、moments 與 seeds。
  • 一次只委派一個可驗證模組，要求同步產生 tests。
  • 要求 AI 解釋 code；若解釋與你的模型不同，先停止 estimation。
  • 整條 pipeline 應 version-controlled，並能用單一 reproducible command 重跑。
  • AI 適合產生 tests、monitoring、plots 與 fast-language translation；研究者負責經濟含義與驗證標準。

方法比較與常見誤解

把 SMM 放回 GMM、indirect inference、calibration 與一般 optimization 的關係中。

方法 比較的 object 適用情境 主要代價
GMM 解析 sample moment restrictions。 \(g(w_i,\theta)\) 可直接計算。 需要能解析評估 parameter-dependent moments。
SMM / MSM data moments 與 simulated moments。 模型可模擬但 moment mapping 無 closed form。 simulation noise、global optimization 與大型驗證工程。
Indirect inference data 與 simulation 的 auxiliary-model estimates。 reduced-form coefficients 能濃縮模型的重要行為。 auxiliary model 的選擇也決定 identification。
Calibration 少數 targeted statistics 或外部 estimates。 探索模型、建立 benchmark、缺乏完整 sampling framework。 通常不自動提供 efficient weighting 與 sampling uncertainty。

常見誤解

「固定 seed 會忽略 simulation uncertainty」

錯。固定 draws 是為了讓 objective 對 \(\theta\) 可比較；推論仍透過 \((1+1/S)\) 納入 simulation noise。optimization control 與 sampling uncertainty 是不同問題。

「moments 越多，identification 越強」

錯。新增高度 correlated 或對 parameters 不敏感的 moments 幾乎不增加 rank， 卻可能放大 covariance estimation 與 specification-test 問題。

「optimizer 找到唯一數字，所以 point identified」

錯。bounds、starting values 或演算法路徑都可能人工選出單一 solution。 Identification 是 population mapping 的唯一性，不是軟體輸出的唯一性。

「\(J\)-test reject，所以模型毫無用處」

不必然。大型樣本會偵測 deliberate simplification。應定位哪些 moments 被拒絕， 再判斷 miss 是否破壞研究中的 counterfactual channel。

SMM 的核心不是把資料 fit 得越好越好。

一個過度彈性的模型可以用許多 parameters fit moments，卻沒有清楚 identification。 好的 structural estimate 需要「有限但與研究問題相關的機制、可解釋的 comparative statics、 足夠而非任意多的 moments，以及透明的 miss diagnostics」。

Preflight checklist

pp.93-94：開始相信 estimates 以前，逐項回答。

  1. 真實與模擬資料使用同一個 moment function、FE、trimming 與 definitions。
  2. Weight matrix 來自 stacked IF 的完整 clustered covariance，且通過 closed-form checks。
  3. 每一組 parameter-moment comparative static 都已畫圖，且能說明經濟機制。
  4. 關閉 frictions 時，solver 與 closed-form special case 達 machine precision。
  5. Shocks 只預抽一次，每次 objective evaluation 使用完全相同的 draws。
  6. Global search 與多個 starting values 得到相同 estimate 和 objective value。
  7. Fake-data Monte Carlo 能回復 parameters，reported SE 具有合理 coverage。
  8. Jacobian step sizes 來自 stability plots，而非未檢查的 defaults。
  9. SE 包含 \((1+1/S)\)，並報告 \(J\)-test 與 individual moment fit。
  10. 不看筆記也能說明哪些 data features 識別每個 parameter，以及哪些 assumptions 支撐該映射。
最後的讀法

這份投影片不是要把 SMM 描述成一個難懂的 estimator，而是要反轉注意力： quadratic objective 很簡單；真正的研究貢獻與風險都在 objective 之前和之後。 之前是 economic question、model 與 moments，之後是 identification、optimization、 inference 與 verification。Coding 變便宜，只會讓「你是否真的理解 estimator」更成為限制。

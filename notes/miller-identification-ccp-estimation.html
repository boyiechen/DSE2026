CCP 方法的核心：把最佳化結果讀回來

觀察 choice frequencies，不只是描述行為，也是在觀察 relative value indices。

CCP = Conditional Choice Probability。 \(p_j(x)=\Pr(d=j\mid x)\) 是 agent 處於 observed state \(x\) 時選 action \(j\) 的機率； 同一 state cell 裡的選擇比例是它的 sample analogue。BLP 的 market share 也有這種 「比例估機率」的意義，但它是條件於 market、choice set 與產品屬性，並把消費者 random coefficients 積分掉的 market-level probability。
一句話： NFXP 對每個 trial parameter 解 Bellman equation；CCP estimator 先從資料估 \(p\) 與 \(f\)，再利用 inversion 和 value representation 把已解出的 optimal behavior 嵌入第二階段。

Population inversion

已知 shock distribution \(g\) 時，CCP vector 與 relative conditional values 一一對應。

Dynamic correction

\(\psi_j(p)=V-v_j\) 把等待 shocks、保留最適選擇權的價值轉成 CCP 的函數。

Primitive recovery

Relative values 加上 transitions 仍不等於 flow utilities；還需要一個 benchmark payoff 或參數限制。

Sequential objectivedynamic choice
\[ \E\!\left[ \sum_{\tau=t}^{T}\sum_{j=1}^{J} \beta^{\tau-t}d_{j\tau} \{u_{j\tau}(x_\tau)+\epsilon_{j\tau}\} \,\middle|\,x_t,\epsilon_t \right]. \]
經濟直覺： 每一期選一個 action，得到 deterministic payoff 加上私人 shock， 並透過 action-specific transition 影響未來 states。因為 agent 已看見本期 \(\epsilon_t\)， 當期 choice 對研究者而言是隨機，對 agent 而言則是 deterministic argmax。
Conditional independencestate reduction
\[ \Pr(x_{t+1},\epsilon_{t+1}\mid x_t,\epsilon_t,d_t=j) = f_{jt}(x_{t+1}\mid x_t)\, g_{t+1}(\epsilon_{t+1}\mid x_{t+1}). \]
經濟直覺： 給定下一期 observed state 後，未來 shock 不再記得本期 shock； 本期 \(\epsilon_t\) 也不直接改變 \(x_{t+1}\)。因此 continuation value 可以只寫成 \(V_{t+1}(x_{t+1})\)，不必把整個 shock history 放進 state。
Choice-specific value 與 CCPobjects
\[ \begin{aligned} v_{jt}(x) &=u_{jt}(x) +\beta\sum_{x'=1}^{X} V_{t+1}(x')f_{jt}(x'\mid x),\\ p_{jt}(x) &=\E[d^o_{jt}(x,\epsilon)\mid x] =\int d^o_{jt}(x,\epsilon)g_t(\epsilon\mid x)d\epsilon. \end{aligned} \]
經濟直覺： \(v_{jt}\) 是承諾選 \(j\) 後、尚未加入本期 \(\epsilon_j\) 的 lifetime value。 CCP 則是在相同 \(x\) 下，多少 shock draws 會讓 \(j\) 成為最大值。 所以 CCP 其實是一個把 relative values 映射成機率的 static random-utility map。

Hotz-Miller inversion：由 CCP 反推 relative values

選擇機率不能告訴我們 value level，但可以告訴我們所有 value differences。

以 action \(J\) 為基準normalization
\[ \Delta v_{jt}(x)=v_{jt}(x)-v_{Jt}(x), \qquad j=1,\ldots,J-1. \]
經濟直覺： 所有 action values 同時加上一個常數不會改變 choice。 因此 \(J\) 個 CCP 中只有 \(J-1\) 個獨立資訊，恰好對應 \(J-1\) 個 relative values。
General random-utility mappingHotz-Miller
\[ p_{-J,t}(x) = Q_t(\Delta v_t(x),x), \qquad \Delta v_t(x) = Q_t^{-1}(p_{-J,t}(x),x). \]
經濟直覺： \(Q_t\) 問的是：給定 payoff differences 與 shock distribution， 哪一部分 shock space 會讓各 action 勝出？Hotz-Miller theorem 說， 在連續 full-support shocks 下，這個 map 對 \(\Delta v\) 可逆。 已知 \(g\) 並觀察 \(p\)，就能反推使這些 choice frequencies 合理的 relative values。
p.7：inverse 是一個 indifference shock differencecompensation
\[ \begin{aligned} v_{jt}(x)+\epsilon'_j &=v_{Jt}(x)+\epsilon'_J\\ \Longrightarrow\qquad \Delta v_{jt}(x) &=\epsilon'_J-\epsilon'_j =Q^{-1}_{jt}[p_t(x),x]. \end{aligned} \]
經濟直覺： \(\epsilon'\) 是位於 choice-region boundary 上的假想 shock，不是平均或實際觀察到的 shock。 若 \(\Delta v_j>0\)，action \(j\) 的 systematic lifetime value 較高； benchmark \(J\) 必須得到比 \(j\) 高 \(\Delta v_j\) 的 taste shock，兩者才會打平。 所以 inverse CCP 是以 shock-scale 單位表示的 compensating value difference。

Binary choice：就是一個 quantile

\(d=j\iff\epsilon_J-\epsilon_j\leq\Delta v_j\)，因此 \[ p_j(x) =F_{\epsilon_J-\epsilon_j\mid x}(\Delta v_j), \qquad \Delta v_j =F^{-1}_{\epsilon_J-\epsilon_j\mid x}(p_j). \] 已知 shock-difference distribution 後，choice frequency 直接指出 value difference 位於哪個 quantile。

多項選擇：要反轉整個 vector

當 \(J>2\)，\(p_j\) 同時受所有 \(\Delta v_k\) 影響，單一 \(p_j\) 不足以反推 \(\Delta v_j\)。講義的 \(Q^{-1}_{jt}\) 是 vector inverse \(Q_t^{-1}\) 的第 \(j\) 個 component，而不是只對 scalar \(Q_{jt}\) 單獨取 inverse。

讓所有 choices 同時無差異location free
\[ \begin{aligned} v_{1t}(x)+\epsilon'_1 &=\cdots =v_{Jt}(x)+\epsilon'_J =c,\\ \epsilon'_J-\epsilon'_j &=v_{jt}(x)-v_{Jt}(x) =\Delta v_{jt}(x). \end{aligned} \]
Normalization： \(c\) 可以任意平移，因此 \(\epsilon'\) 的 absolute levels 不唯一；被識別的是 \(J-1\) 個 shock differences。若設 \(\epsilon'_J=0\)，則 \(\epsilon'_j=-\Delta v_j\)。這和所有 choice values 同加一個常數不影響選擇是同一件事。
T1EV 的熟悉版本：log oddsclosed form
\[ p_{jt}(x) = \frac{\exp(v_{jt}(x)/\sigma)} {\sum_{k=1}^{J}\exp(v_{kt}(x)/\sigma)} \quad\Longrightarrow\quad v_{jt}(x)-v_{Jt}(x) = \sigma\log\frac{p_{jt}(x)}{p_{Jt}(x)}. \]
經濟直覺： 一個 action 比 benchmark 多被選多少，直接揭露它高出多少 lifetime value。 \(\sigma\) 是 utility scale；若 normalize \(\sigma=1\)，relative value 就是 log CCP odds。

與 market-share／BLP inversion 的精確對應

若市場 \(m\) 有 \(M_m\) 位潛在消費者， \(\widehat s_{jm}=M_m^{-1}\sum_i1\{d_{im}=j\}\) 在大市場下收斂到 \(\Pr(d_i=j\mid m)\)。所以 market share 確實是 market-level choice probability； 但若分母只含實際購買者，它是 conditional-on-purchase share，並不是標準 BLP 包含 outside option 的 market share。

共同的 convex-surplus 骨架same principle
\[ \mathcal S(a) =\E\!\left[\max_j\{a_j+\epsilon_j\}\right], \qquad m_j =\frac{\partial\mathcal S(a)}{\partial a_j}, \qquad a =(\nabla\mathcal S)^{-1}(m). \]
經濟直覺： Expected maximum 對某個 value index 的邊際效果，正是該 choice 勝出的機率。 Hotz-Miller 與 BLP 都把 observed probability/share 反轉成 latent utility indices； 差別在 \(a\)、被積分的 heterogeneity，以及 inversion 後要接回的結構。

DDC / Hotz-Miller

\[ p(x)=Q(\Delta v(x);G_\epsilon) \quad\Longrightarrow\quad \Delta v(x)=Q^{-1}(p(x);G_\epsilon). \] 給定 observed dynamic state \(x\)，通常只積分本期 transitory shocks； 反推出的是包含 continuation value 的 lifetime-value differences。

Random-coefficient BLP

\[ \begin{aligned} u_{ijm} &=\delta_{jm}+\mu_{ijm}(\nu_i;\theta_2)+\epsilon_{ijm},\\ s_{jm}(\delta_m;\theta_2) &=\int P_{ijm}(\nu;\delta_m,\theta_2)dF(\nu). \end{aligned} \] 給定 \(\theta_2\)，反轉 \(s_m(\delta_m;\theta_2)=S_m^{obs}\) 得到 product-market mean utilities \(\delta_m\)。

兩個 probability maps 的 Jacobianlocal invertibility
\[ \begin{aligned} \frac{\partial p_j}{\partial v_k} &= \frac{1}{\sigma}p_j \left(1\{j=k\}-p_k\right) &&\text{(T1EV CCP)},\\ \frac{\partial s_j}{\partial\delta_k} &= \int P_{ij}(\nu) \left(1\{j=k\}-P_{ik}(\nu)\right)dF(\nu) &&\text{(BLP)}. \end{aligned} \]
數學對應： 兩者的 diagonal 都為正、cross effects 都為負。BLP Jacobian 是 individual-logit Jacobians 對 \(\nu\) 的平均；outside-good normalization 移除共同 location 後， 這個 curvature 提供 inversion 的局部識別。Random coefficients 也使 inverse 不再等於逐產品的單純 log-share difference。
BLP 沒有 closed form 時的 Berry contractioninner inversion
\[ \delta_m^{(r+1)} = \delta_m^{(r)} +\log S_m^{obs} -\log s_m(\delta_m^{(r)};\theta_2). \]
計算差異： Simple logit BLP 的 \(\delta_{jm}=\log S_{jm}-\log S_{0m}\) 與 T1EV CCP log odds 是同一公式。加入 random coefficients 後，shares 已對 \(\nu_i\) 積分，inverse 通常沒有 closed form，而且每個 trial \(\theta_2\) 都要重新求 \(\delta\)。 基本 CCP inversion 在 \(G_\epsilon\) 固定後通常只做一次 first stage。

Conditional value correction \(\psi\)

它衡量「等 shocks 出現後再選」相對於事前承諾某個 action 的 option value。

從 realized maximum 到 correctionoption value
\[ \begin{aligned} W_t(x,\epsilon) &=\max_k\{v_{kt}(x)+\epsilon_{kt}\},\\ V_t(x) &=\E[W_t(x,\epsilon)\mid x],\\ \psi_{jt}(x) &=V_t(x)-v_{jt}(x). \end{aligned} \]
經濟直覺： \(V_t(x)\) 允許 agent 看完所有 shocks 再挑最佳 action； \(v_{jt}(x)\) 則固定 deterministic part 為 action \(j\)。 若事前承諾 \(j\)，期望 lifetime utility 是 \(v_{jt}(x)+\E[\epsilon_{jt}|x]\)， 所失去的最適選擇權價值為 \(\psi_{jt}(x)-\E[\epsilon_{jt}|x]\)。
這不是統計上的 bias correction。 它補的是 choice flexibility。真正的 commitment loss 是 \(V_t-[v_{jt}+\E(\epsilon_{jt}\mid x)] =\psi_{jt}-\E(\epsilon_{jt}\mid x)\geq0\)； 只有在 \(\E(\epsilon_{jt}\mid x)=0\) 的 normalization 下，loss 才直接等於 \(\psi_{jt}\)。
不能寫成 \(V_t(x)=\sum_jp_{jt}(x)v_{jt}(x)\)。 Agent 正是因為某個 \(\epsilon_j\) 相對高才選 \(j\)，所以 \(\E[\epsilon_j\mid d=j,x]\neq\E[\epsilon_j\mid x]\)。 單純用 CCP 加權 deterministic values，會漏掉「被選中 shock 特別有利」的 selection term。
Why CCPs identify \(\psi\)identified correction
\[ \begin{aligned} V_t(x)-v_{it}(x) ={}& \sum_{j=1}^{J}p_{jt}(x) [v_{jt}(x)-v_{it}(x)]\\ &+ \sum_{j=1}^{J} \int \epsilon_{jt}d^o_{jt}(x,\epsilon) g_t(\epsilon\mid x)d\epsilon. \end{aligned} \]
經濟直覺： 第一部分的 value differences 由 CCP inversion 給出； 第二部分是「在 \(j\) 勝出的 shock region 裡，被選中 shock 的期望」， 只要 \(g\) 已知也能計算。因此 \(\psi_i\) 是 \(p\) 與 \(g\) 的已知函數。
i.i.d. T1EV correctionlogit
\[ \psi_j(p)=\gamma-\sigma\log p_j, \]
經濟直覺： \(p_j\) 越小，承諾選 \(j\) 的機會成本越高，所以 correction 越大。 \(\gamma\) 是由 EV1 location/scale normalization 決定的常數；標準 unit-scale 參數化下是 Euler constant，scale 為 \(\sigma\) 的另一常見寫法則是 \(\sigma\gamma_E-\sigma\log p_j\)。這個共同常數通常會被 utility normalization 吸收。 這條式子是 CCP estimator 能把 expected future maxima 換成 observed probabilities 的關鍵。
Extended nested logit correction
\[ \psi_j(p) = \gamma-\sigma\log p_j -(1-\sigma)\log\!\left(\sum_{k\in\mathcal J(j)}p_k\right). \]

\(\mathcal J(j)\) 是包含 \(j\) 的 nest。Correction 只需要同一 nest 裡的 CCPs； nest 外有多少 choices 或它們如何相關，都不進入這一項。當 \(\sigma=1\) 時， 回到 independent EV1 的 \(\gamma-\log p_j\)。

Value representation：不做 recursive maximization

選一個 baseline action 1，沿著它向前 telescoping；最適行為已包含在 CCP corrections。

先向前展開一期telescoping
\[ \begin{aligned} v_{jt}(x) &= u_{jt}(x) +\beta\sum_{x'}V_{t+1}(x')f_{jt}(x'|x)\\ &= u_{jt}(x) +\beta\sum_{x'} \left[v_{1,t+1}(x')+\psi_{1,t+1}(x')\right] f_{jt}(x'|x). \end{aligned} \]
經濟直覺： 任何 ex ante value 都可寫成「承諾 baseline action 1 的 conditional value」 加上等待 shocks 後再最佳化的 correction。重複代入 \(v_1\)，就能把 Bellman recursion 展開成 discounted future flows。
Representation theoremArcidiacono-Miller
\[ \begin{aligned} v_{jt}(x) ={}&u_{jt}(x)\\ &+ \sum_{\tau=t+1}^{T}\sum_{x_\tau=1}^{X} \beta^{\tau-t} \left\{ u_{1\tau}(x_\tau) +\psi_1[p_\tau(x_\tau)] \right\} \kappa_{\tau-1}(x_\tau\mid x,j). \end{aligned} \]
經濟直覺： \(\kappa_{\tau-1}(x_\tau|x,j)\) 是本期先選 \(j\)，之後沿 baseline action 1 前進時抵達 \(x_\tau\) 的機率。這條 path 不必是 optimal； 每一期的 \(\psi_1(p)\) 會補回「沒有等 shocks 再選」的損失。 因此 recursive maximization 消失，但 optimal solution 仍透過 observed CCPs 留在式子裡。
沒有 Bellman solve，不代表沒有 dynamics。 Estimator 仍要知道 \(\beta\)、transition \(f\)、未來 CCPs 與 horizon。 CCP approach 只是把「反覆最大化」換成「先估 reduced forms，再做 discounted integration」。

Flow utility primitives 到底如何識別？

講義先假設 \((T,\beta,f,g)\) 已知，再問 panel \((x_t,d_t)\) 能否識別 \(u\)。

答案： 只靠 behavior 無法識別每個 state-time 的 absolute utility level。 若每個 \((x,t)\) 有一個 benchmark action payoff 已知，其餘 flow utilities 就能由 CCP corrections 與不同 initial choices 所造成的 future-state differences 恢復。
p.15：任選一個 state-time benchmarkobservational equivalence
\[ l(x,t)\in\{1,\ldots,J\}, \qquad u^*_{l(x,t),t}(x)=c_t(x), \qquad \sup_t|c_t(x)|<\infty. \]
經濟直覺： 在每個 \((x,t)\) 任選一個 normalizing action \(l(x,t)\)，再任意指定一個 bounded benchmark flow \(c_t(x)\)。對任何這樣的 \(\{c_t(x)\}\)，都能同步調整其他 current payoffs，抵銷它對 continuation values 的影響，使所有 choice-specific value differences、CCPs 與 observed histories 完全不變。反過來，每一個 observationally equivalent payoff system 都可由某組 \(c_t(x)\) 描述。
不只缺一個全域常數。 Unrestricted dynamic model 原則上在每個 state-time 都缺一個 payoff anchor。 提高某個 future-state 的共同 value level，會改變今天各 actions 的 continuation values； 但只要把今天通往該 state 的 actions 之 current payoffs 反向調整，choices 仍然一樣。
由 lifetime-value difference 拆回 current flowBellman difference
\[ \begin{aligned} \Delta v_{jt}(x) &\equiv v_{jt}(x)-v_{1t}(x) =\psi_{1t}(x)-\psi_{jt}(x)\\ &= u_{jt}(x)-u_{1t}(x) +\beta\sum_{x'}V_{t+1}(x') \left[f_{jt}(x'|x)-f_{1t}(x'|x)\right],\\[3pt] u_{jt}(x) &= u_{1t}(x)+\psi_{1t}(x)-\psi_{jt}(x)\\ &\quad+ \beta\sum_{x'}V_{t+1}(x') \left[f_{1t}(x'|x)-f_{jt}(x'|x)\right]. \end{aligned} \]
經濟直覺： CCP inversion 告訴我們 \(j\) 相對於 1 的 lifetime advantage； transition difference 告訴我們其中有多少來自較好的 future states。 把 continuation advantage 扣掉，剩下的才是 current flow advantage。 若 \(j\) 是一項會改善未來的投資，它今天的 \(u_j\) 可以很低，仍然有很高的 \(v_j\)。

Terminal period

\(T\) 期沒有 continuation value，因此 \[ u_{jT}(x) = u_{1T}(x)+\psi_{1T}(x)-\psi_{jT}(x). \] 一旦 \(u_{1T}(x)\) 已知，terminal-period 的所有 flow payoffs 都能恢復。

Backward identification

已知 \(u_T\) 後即可算 \(V_T\)，再用 \(f_{j,T-1}\) 恢復 \(u_{j,T-1}\)； 如此從 \(T\) 一路向後到 \(t=1\)。這就是「每個 state-time 一個 benchmark payoff」 足以 point identify 其餘 \(J-1\) 個 payoffs 的原因。

Identification formulaknown benchmark
\[ \begin{aligned} u_{jt}(x) ={}& u_{1t}(x) +\psi_{1t}(x)-\psi_{jt}(x)\\ &+ \sum_{\tau=t+1}^{T}\sum_{x_\tau=1}^{X} \beta^{\tau-t} \left[u_{1\tau}(x_\tau)+\psi_{1\tau}(x_\tau)\right]\\ &\qquad\qquad\times \left[ \kappa_{\tau-1}(x_\tau|x,1) -\kappa_{\tau-1}(x_\tau|x,j) \right]. \end{aligned} \]
經濟直覺： Action \(j\) 相對於 benchmark 1 的 current utility，由兩塊決定： 當期等待 shocks 的 correction gap，以及兩個 initial choices 對未來 state distributions 的差異。若 \(u_{1t}(x)\) 已知，右邊其餘物件都由 \(p,f,g,\beta\) 決定。
Static special case： 若所有 actions 具有相同 transition， \(f_{jt}(x'|x)=f_{1t}(x'|x)\)，則所有 \(\kappa\) differences 消失， 識別式退化成 \(u_{jt}(x)-u_{1t}(x)=\psi_{1t}(x)-\psi_{jt}(x)\)。 動態模型額外需要 transitions，正是因為選擇會改變未來。

Utility level

同一 \((x,t)\) 的所有 payoffs 可以被重新標定並搭配 future adjustments，choices 仍不變。

Shock scale

通常 normalize \(g\) 的 scale，例如 T1EV 的 \(\sigma=1\)，否則只識別 utility/scale ratios。

Discount factor

本講義把 \(\beta\) 當已知；只靠 choices 和 transitions 通常不能無條件地識別 \(\beta\)。

Setting \(u_1(x)=0\) 是 normalization，不是資料發現。 它選出 observational-equivalence class 的一個代表。若要識別 \(\beta\)、shock scale 或有直接 welfare 意義的 utility levels，通常需要額外 exclusion restrictions、 payoff information 或 functional-form restrictions。若 benchmark payoff 來自真正的 exit value、scrap value 或會計成本，它提供經濟識別；若只是任意設為零，原始 choices 的預測可以不受影響，但 welfare level 或改變 benchmark payoff 的 counterfactual 不應被解讀成由資料本身識別。

Unrestricted first stage：直接估 \(p\) 與 \(f\)

有限 state space 下，最自然的是 cell-frequency MLE。

CCP cell estimatorchoice frequency
\[ \widehat p_{jt}(x) = \frac{\sum_n 1\{x_{nt}=x,d_{nt}=j\}} {\sum_n 1\{x_{nt}=x\}}. \]
經濟直覺： 在同一 state-time cell 裡，選 \(j\) 的樣本比例就是 CCP 的 unrestricted MLE。
Transition cell estimatorstate law
\[ \widehat f_{jt}(x'|x) = \frac{\sum_n1\{x_{nt}=x,d_{nt}=j,x_{n,t+1}=x'\}} {\sum_n1\{x_{nt}=x,d_{nt}=j\}}. \]
經濟直覺： 只看在 \(x\) 選 \(j\) 的 observations，下一期落到 \(x'\) 的比例就是 action-specific transition。
在 unrestricted finite-cell model 中，\(\widehat p,\widehat f\) 都是 MLE， 具有標準的 \(\sqrt N\) asymptotic normality。若 flow utilities exactly identified， plug-in estimator 也可藉 invariance principle 達到相應 efficiency bound。 額外效率只能來自對 \(u\) 或 \(f\) 加入 functional-form restrictions。

Sparse cells

State、time、choice 維度一大，很多 cells 沒資料，\(\widehat p\) 與 \(\widehat f\) 會非常不穩。

Zero CCPs

T1EV inversion 需要 \(\log p_j\)；sample zero 會產生 \(-\infty\)，通常需 smoothing 或 parametric first stage。

Generated regressors

第二階段把 \(\widehat p,\widehat f\) 當輸入，standard errors 必須包含 first-stage estimation error。

Finite dependence：讓遠期 continuation values 抵消

不是假設 agent 只看幾期，而是構造 paths，使不同 initial choices 的 state distributions 在有限期後相同。

\(\rho\)-period dependencedistribution matching
\[ \kappa^{(\omega^i)}_{t+\rho+1} (x_{t+\rho+1}\mid i,t,x) = \kappa^{(\omega^j)}_{t+\rho+1} (x_{t+\rho+1}\mid j,t,x) \quad\forall x_{t+\rho+1}. \]
經濟直覺： 本期分別從 \(i\) 與 \(j\) 出發，之後使用兩組加權 choice sequences。 如果 \(\rho+1\) 期後抵達每個 state 的機率完全一樣， 那麼從該期開始的 \(V_{t+\rho+1}\) 在 value difference 中整塊抵消。 Estimator 只需估到有限期的 CCP corrections。
\(\omega\) 不一定是可執行 policy probabilities。 講義的 search example 中，某些 weights 可以大於 1 或為負；它們是用來匹配 transition distributions 的 algebraic weights，只要求對 choices 加總為 1，不必都落在 \([0,1]\)。

Terminal choice

選了就結束問題，continuation value 為零。Exit、退休、死亡或採用不可逆技術常具有這種結構。

Renewal choice

下一期 state distribution 不依賴目前 state，例如更換引擎後 mileage reset。初始差異很快被洗掉。

在 CI 下，finite dependence 只涉及 transition matrices，因此在不指定 flow utilities 的情況下也具有可檢驗內容。 它可以只對某些 action pairs 或 states 成立；不需要整個模型 everywhere 都有同一個 \(\rho\)。
11

Relaxing CI：hidden types 與 EM

Persistent unobserved heterogeneity 讓目前 choice shock 帶有未來資訊；conditional on type 後可恢復 CCP 邏輯。

E-step：個體屬於 type \(s\) 的 posteriorresponsibility
\[ q_{ns}^{(m+1)} = \frac{ \pi_s^{(m)} \prod_{t=1}^{T} \ell(d_{nt}\mid x_{nt},s,p^{(m)},\theta^{(m)}) }{ \sum_{s'=1}^{S} \pi_{s'}^{(m)} \prod_{t=1}^{T} \ell(d_{nt}\mid x_{nt},s',p^{(m)},\theta^{(m)}) }. \]
經濟直覺： 如果個體 \(n\) 的整段 choice history 在 type \(s\) 下更可能， posterior weight \(q_{ns}\) 就更高。Long panel 幫助模型從反覆行為中學到 persistent type。
M-step：更新 type shares 與 type-specific CCPsweighted cells
\[ \begin{aligned} \pi_s^{(m+1)} &= \frac{1}{N}\sum_{n=1}^{N}q_{ns}^{(m+1)},\\ p_j^{(m+1)}(x,s) &= \frac{ \sum_n\sum_t d_{jnt}q_{ns}^{(m+1)}1\{x_{nt}=x\} }{ \sum_n\sum_t q_{ns}^{(m+1)}1\{x_{nt}=x\} }. \end{aligned} \]
經濟直覺： 每筆 observation 不再硬分到某個 type，而是按 posterior fractional membership 加權。接著用同樣 weights 最大化 quasi likelihood 更新 \(\theta\)，反覆迭代到收斂。

Initial values

Mixture likelihood 常有 local maxima，應使用多組起始值並比較 objective。

Label switching

Type labels 本身沒有意義，需要排序 normalization 或以 economically meaningful statistic 命名。

Short panels

每個人觀察期太短時，很難分辨 persistent type 和一連串 temporary shocks。

Entry-exit game：terminal choice 的應用

企業面對競爭、persistent demand shock 與 startup cost；exit 是 payoff normalized to zero 的 terminal action。

Price/revenue equationobserved outcome
\[ y_t = \alpha_0+\alpha_1x_1+\alpha_2s_t +\alpha_3\sum_{i=1}^{I}d_{2t}^{(i)} +\eta_t. \]
經濟直覺： Revenue 由 permanent market type、Markov demand state 與 active competitors 決定。 \(s_t\) 對研究者不可見，會同時影響 prices 和 entry/exit choices； 忽略它容易把 persistent demand 誤認成競爭效果。
Expected active profitstrategic CCPs
\[ u_2^{(i)}(x_t,s_t) = \theta_0+\theta_1x_1+\theta_2s_t +\theta_3\sum_{i'\ne i}p_2^{(i')}(x_t,s_t) +\theta_4\,1\{\text{entrant }i\}. \]
經濟直覺： Firm \(i\) 不知道 competitors 的 private shocks，但知道它們進入或留下的 equilibrium CCPs， 所以 expected competition 用 \(\sum p_2^{(i')}\) 表示。Entrant 額外支付 startup cost \(\theta_4\)。
Exit-terminal representationfinite dependence
\[ v_2^{(i)}(x_t,s_t) = u_2^{(i)}(x_t,s_t) -\beta\sum_{x,s} \log p_1^{(i)}(x,s)\, f_2^{(i)}(x,s\mid x_t,s_t). \]
經濟直覺： Exit action 1 結束 firm 的問題並把 payoff normalize 為零。 在 T1EV 下，baseline correction 是 \(-\log p_1\) 加共同常數； 因此 active value 只需 current profit、下一期 transition 和 future exit CCP， 不必解完整 game 的 value fixed point。
Monte Carlo 比較的重點不是某一欄數字，而是 information assumptions： demand state 是否 observed、CCPs 是由 data cells 還是 model 更新、prices 是否可見， 都會改變 bias、precision 與 runtime。忽略 persistent hidden state 尤其容易污染 competition 與 state coefficients。

實作與閱讀檢查表

CCP estimator 快不快是第二順位；先確認 inversion 所需的資訊真的存在。

Shock distribution 是否可信？

\(Q^{-1}\) 完全依賴 \(g\)。錯誤的 correlation 或 scale specification 會直接扭曲 recovered values。

CCP support 是否足夠？

每個 relevant state-choice cell 都需要正且可精確估計的 CCP；zero cells 不是小數值問題。

Normalization 說清楚了嗎？

Benchmark payoff、shock scale 與 discount factor 哪些已知、哪些估計，決定 identification claim 的範圍。

Finite dependence 真的成立嗎？

應從 estimated transition laws 驗證 distribution matching，而不是只因模型看起來像 renewal 就假設成立。

Persistent heterogeneity 處理了嗎？

若 hidden type 同時影響 choices 與未來，直接 pooled CCPs 會破壞 conditional independence。

Inference 包含 first stage 嗎？

第二階段的 \(\widehat\psi,\widehat h\) 都是 generated regressors；bootstrap 或 analytical variance 必須反映它們的估計誤差。

最短的 mental model
  1. Observed CCPs 加上已知 \(g\)，給 relative conditional values。
  2. CCPs 也給等待 shocks 再選的 correction \(\psi\)。
  3. Transitions 把 corrections 和 benchmark flows 沿未來 states 加總。
  4. 一個 benchmark payoff 或 parametric restriction 把 flow utility level 固定下來。
  5. Finite dependence、terminal 或 renewal structure 讓遠期 continuation values 更快抵消。
最後的判斷： CCP estimation 不是免費避開動態模型，而是把 computational burden 從 repeated optimization 移到 first-stage behavior、transition estimation 與 identification assumptions。 當 CCPs 好估、state transitions 有結構時非常漂亮；當 state space 稀疏或 hidden heterogeneity 很強時， 它也會把問題放大得很誠實。

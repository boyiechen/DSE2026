Lecture 3 · Equilibrium Trade in Automobiles

DNFXP：汽車新舊市場的動態均衡模型

這份筆記把 Doubly Nested Fixed Point 拆成三個會彼此回饋的經濟物件： 家戶的動態選擇、二手車市場的均衡價格，以及用資料估計的結構參數。 重點不只是「怎麼算」，而是每一層 fixed point 到底要求哪一種行為或市場狀態保持一致。

1

一眼看懂 DNFXP

為什麼它叫「doubly nested」，以及每一層到底在固定什麼。

一句話： NFXP 在每個 \(\theta\) 下解一次個體 DP；DNFXP 還必須在 DP 外面找一組二手車價格， 使家戶最適行為所產生的需求與供給恰好一致。

Bellman consistency

\(EV^\star=\Gamma(EV^\star;P,\theta)\)

家戶對未來的價值評估，必須等於按照最適行為向前推一期後得到的價值。

Market consistency

\(\ED(P^\star,q(P^\star))=0\)

價格要調到每一種「車型 × 車齡」的二手車需求量等於供給量。

Statistical consistency

\(\widehat\theta=\arg\max_\theta L(\theta)\)

結構參數要讓均衡模型預測的家庭狀態轉移，對實際資料給出最高機率。

「Double」不是說模型只有兩個方程。 對每個 \(\theta\)，equilibrium solver 要搜尋 \(P^\star\)；而每一次試算 \(P\) 又要解家戶的 Bellman fixed point。固定分布 \(q=q\Omega Q\) 也是一個 fixed-point condition，但它是有限 Markov chain 的 stationary distribution，通常可用線性代數直接求。

經濟環境與符號

新車供給與報廢需求是外生的，二手車價格則由模型內生決定。

\(\varnothing\)

Purge：不再持有車

  • \(s=1_s\)：scrap，拿報廢價
  • \(s=0_s\)：sell，在二手市場出售
\(\kappa\)

Keep：繼續持有

  • 本期享受現有車服務
  • 下期車齡增加或因事故進入 terminal age
\(j,d\)

Replace：換成另一台車

  • 買入車型 \(j\)、車齡 \(d\)
  • 原車同時選擇 sell 或 scrap
符號定義經濟角色
\((i,a)\)目前持有的車型與車齡家戶的 endogenous ownership state
\((j,d)\)打算買入的車型與車齡replace choice 的標的
\(\bar a\)terminal age事故全損或車輛物理壽命終點
\(P_{jd}\)車型 \(j\)、車齡 \(d\) 的價格\(d=0\) 的新車價外生；可交易二手車價內生
\(\underline P_i\)車型 \(i\) 的報廢價格外生且有完全彈性的 scrap demand
\(T_b,T_s\)買方與賣方 transaction costs在買賣價差之外形成交易楔子
\(\mu\)金錢的邊際效用把貨幣成本轉為 utility units
\(\alpha_i\)車型 \(i\) 的全損機率物理狀態轉移，不是家戶選擇
\(q_{ia}\)持有 \((i,a)\) 的人口比例市場供需的 aggregate state
單期效用的骨架preferences
\[ U(i,a,c)=u(i,a)-\mu\,C(i,a,c;P)+\epsilon(c). \]
經濟直覺： \(u(i,a)\) 是車輛服務與維修負擔的淨效用，通常隨車齡下降； \(C\) 是選擇 \(c\) 所造成的淨貨幣支出；\(\epsilon(c)\) 捕捉研究者看不到、 但家戶當期知道的偏好。價格乘上 \(\mu\)，才可和 utility 直接比較。
3

家戶的動態選擇：五條 choice-specific value

每條式子都遵循「本期車輛服務 − 淨支出 + 折現後未來價值」。

離開市場並報廢原車purge + scrap
\[ v(i,a,\varnothing,1_s) =u(\varnothing)+\mu\underline P_i+\beta\EV(\varnothing). \]
經濟直覺： 家戶下一期進入「無車」狀態；本期不再享受汽車服務，但拿到報廢價 \(\underline P_i\)。報廢價越高，老車退出市場的誘因越強。
離開市場並出售原車purge + sell
\[ v(i,a,\varnothing,0_s) =u(\varnothing)+\mu\!\left[P_{ia}-T_s(P,i,a)\right] +\beta\EV(\varnothing). \]
經濟直覺： 賣車收入不是 \(P_{ia}\) 全部進入口袋，還要扣賣方交易成本 \(T_s\)。 所以交易成本會創造一個 inaction region：即使家戶不太喜歡現有車，也可能不值得出售。
保留現有車keep
\[ v(i,a,\kappa) =u(i,a) +\beta(1-\alpha_i)\EV(i,a+1) +\beta\alpha_i\EV(i,\bar a). \]
經濟直覺： 車子以 \(1-\alpha_i\) 的機率正常老一歲，以 \(\alpha_i\) 的機率因全損事故跳到 terminal state。這是「物理風險」對 continuation value 的機率加權，不是家戶把 \(\alpha_i\) 比例的車主動報廢。
買入 \((j,d)\)，並報廢原車replace + scrap
\[ \begin{aligned} v(i,a,j,d,1_s) ={}&u(j,d) -\mu\!\left[P_{jd}-\underline P_i+T_b(P,j,d)\right] \\ &+\beta(1-\alpha_j)\EV(j,d+1) +\beta\alpha_j\EV(j,\bar a). \end{aligned} \]
經濟直覺： 淨支出是新持有車的價格，加上買方交易成本，再扣掉原車報廢收入。 換車決策同時比較「今天要補多少錢」與「買到的車未來還值多少效用」。
買入 \((j,d)\)，並出售原車replace + sell
\[ \begin{aligned} v(i,a,j,d,0_s) ={}&u(j,d) -\mu\!\left[P_{jd}-P_{ia}+T_s(P,i,a)+T_b(P,j,d)\right] \\ &+\beta(1-\alpha_j)\EV(j,d+1) +\beta\alpha_j\EV(j,\bar a). \end{aligned} \]
經濟直覺： 這是完整的 replacement wedge：買入價減賣出價，再加兩側交易成本。 \(T_b+T_s\) 越大，家戶越不常換車，二手市場越薄，車也更可能直接持有到報廢。
為什麼需要這麼多條？ 一個完整 action 不只是 keep 或 replace，而是必須同時指定： 下一期要不要持有車、若換車要買哪個 \((j,d)\)，以及原車要 sell 還是 scrap。 每個完整 action 都有不同的 cash flow、下一期 ownership state 與 aggregate market flow。
五條式子的共同骨架one template
\[ v(x,c) = u(x,c;P,\theta) -\mu C(x,c;P) +\beta\sum_{x'}p(x'\mid x,c;\theta)\EV(x'). \]
經濟直覺： 理論上可以只寫這一條 generic equation，但計算時仍要把每個 \(c\) 展開。 否則無法判斷原車是進入 used-car supply 還是退出實體車 stock，也無法知道買入行為形成哪一個 \((j,d)\) 市場的 demand。
Sell 或 scrap 的 separabilitydisposal margin
\[ \begin{aligned} &v(i,a,j,d,0_s)-v(i,a,j,d,1_s)\\ &\qquad =\mu\left[P_{ia}-T_s(P,i,a)-\underline P_i\right]. \end{aligned} \]
經濟直覺： 比較 sell 與 scrap 時，新買車的效用、買入價格、買方交易成本和 continuation value 全部抵消。 沒有當期 taste shocks 時，只要原車的淨二手收入 \(P_{ia}-T_s\) 高於報廢價 \(\underline P_i\)，sell 就優於 scrap。 這也是講義所說 disposal decision 可以和買哪台車部分分離的原因。

Keep vs. replace

決定 ownership state 是否改變，因而決定未來 value 與車齡 transition。

Sell vs. scrap

決定原車成為二手市場供給，或直接退出可交易的 physical stock。

Which \((j,d)\)

決定哪個細分市場產生需求，也決定新車的服務流、老化路徑與事故風險。

別漏掉價格的雙重角色： \(P_{ia}\) 對現有車主是 potential sale value，\(P_{jd}\) 對買方則是 acquisition cost。 因此同一個價格變動會同時改變供給與需求，這正是 equilibrium feedback 的來源。

整合 taste shocks：EV、CCP 與 Bellman operator

EV1/GEV 讓高維離散選擇的 expected maximum 可以解析計算。

EV 不是直接對 choices 取平均。 家戶先看到自己的 choice-specific shocks，再選 value 最大的 action； econometrician 最後才把看不到的 shocks 積分掉。因此正確順序是 \(E_\epsilon[\max_c\{\cdot\}]\)，不是 \(\max_c E_\epsilon[\cdot]\)，也不是單純的 \(\sum_c\Pi(c\mid x)v(x,c)\)。

observed ownership state

step 2抽到 \(\epsilon\)

各 action 的私人 taste shocks

step 3家戶看見 shocks

研究者看不見

step 4選 \(c^\star\)

最大化 \(v+\epsilon\)

step 5積分 \(\epsilon\)

得到 ex ante \(EV(x)\)

Ex post value 與 ex ante integrated valuetiming
\[ \begin{aligned} V(x,\epsilon) &=\max_{c\in\mathcal C(x)} \left\{v(x,c)+\epsilon(c)\right\},\\ \EV(x) &=E_\epsilon\!\left[V(x,\epsilon)\mid x\right]\\ &=E_\epsilon\!\left[ \max_{c\in\mathcal C(x)} \{v(x,c)+\epsilon(c)\} \,\middle|\,x \right]. \end{aligned} \]
經濟直覺： \(V(x,\epsilon)\) 是家戶已經看見本期 shocks 後的 value； \(\EV(x)\) 則是在只知道 observed state \(x\)、尚未知道這期特別偏好哪個 action 時的 ex ante value。 Choice \(c^\star(x,\epsilon)\) 是 shocks 的函數，所以積分 shocks 會間接產生 choice probabilities， 但 integration variable 仍然是 \(\epsilon\)，不是 choice label。
Expected value 的 log-sumintegrated value
\[ \EV(x) = \sigma\log\!\left[ \sum_{c\in\mathcal C(x)} \exp\!\left(\frac{v(x,c)}{\sigma}\right) \right]. \]
經濟直覺： log-sum 是「平滑後的最大值」。\(\sigma\) 小時，幾乎只有 deterministic value 最高的選項有權重； \(\sigma\) 大時，未觀察偏好較重要，次佳選項也有可觀的選擇機率。它同時衡量 available options 所帶來的 option value。式子可能差一個由 EV1 location normalization 決定的共同常數； 講義把它正規化掉。
對 state \(x=(i,a)\)，完整 action set \(\mathcal C(x)\) 包含 keep \(\kappa\)、purge-and-dispose \((\varnothing,s)\)，以及所有 replace choices \((j,d,s)\)。因此 p.13 的每一條 choice-specific value 都是這個 log-sum 裡的一個 alternative family。
先用任意 candidate \(W\) 定義 Bellman operatoroperator
\[ \begin{aligned} v_W(x,c;P,\theta) &= u(x,c;\theta)-\mu C(x,c;P) +\beta\sum_{x'}p(x'\mid x,c;\theta)W(x'),\\ [\Gamma(W,P;\theta)](x) &= E_\epsilon\!\left[ \max_{c\in\mathcal C(x)} \{v_W(x,c;P,\theta)+\epsilon(c)\} \right]\\ &= \sigma\log\!\left[ \sum_{c\in\mathcal C(x)} \exp\!\left(\frac{v_W(x,c;P,\theta)}{\sigma}\right) \right]. \end{aligned} \]
經濟直覺： 先不要假設 \(W\) 已經是正確的 lifetime value。Operator \(\Gamma\) 把目前猜測的 \(W\) 放進所有 continuation values，讓家戶重新最佳化，再積分掉 shocks， 最後輸出一個更新後的 value vector。p.13 的五類式子正是第一行在不同 actions 下的展開。
Bellman fixed pointDP consistency
\[ \EV(P)=\Gamma\!\left(\EV(P),P;\theta\right). \]
經濟直覺： 左邊是家戶目前相信各 ownership state 的未來價值，右邊是用這些價值做最適選擇後重新算出的價值。 fixed point 要求兩者一致。寫成 \(\EV(P)\) 是在提醒：即使偏好參數不變，均衡價格改變也會重塑整張 value function。
Conditional choice probabilitybehavior
\[ \Pi(c\mid x;P) = \frac{\exp[v(x,c)/\sigma]} {\sum_{k\in\mathcal C(x)}\exp[v(x,k)/\sigma]}. \]
經濟直覺： 一個選項的機率取決於它相對於所有其他選項的 value。價格不直接出現在符號左側， 卻透過每一條 \(v\) 影響 CCP；因此 \(\Pi\)、交易流量與持有分布都隱含依賴 \(P\)。
為什麼 EV 不等於 choice-weighted averageoption value
\[ \begin{aligned} \EV(x) &\neq \sum_c\Pi(c\mid x)v(x,c),\\ \EV(x) &= \sum_c\Pi(c\mid x)v(x,c) -\sigma\sum_c\Pi(c\mid x)\log\Pi(c\mid x),\\ \frac{\partial \EV(x)}{\partial v(x,c)} &=\Pi(c\mid x). \end{aligned} \]
經濟直覺： 第一個總和只平均 deterministic values，第二個 entropy term 則保留未觀察偏好與多個可選方案帶來的 option value。 CCP 是 log-sum 對某個 alternative value 的邊際反應，但 log-sum 本身不是只用 CCP 做加權平均。

把 \(EV\) 壓縮成 observed-state function 所需的假設

假設在推導中的作用若沒有
Additive separability \(U(x,c,\epsilon)=v(x,c)+\epsilon(c)\)，可把 deterministic value 與 shock 分開。 Expected maximum 通常不能只由一組 choice-specific \(v\) 表示。
Conditional independence 給定 \(x'\) 後，未來 shocks 不依賴本期 \(\epsilon\)，continuation value 可寫成 \(\EV(x')\)。 目前 shock 會成為 persistent hidden state，state space 必須擴張。
Markov state \(p(x'\mid\text{history},x,c)=p(x'\mid x,c)\)，目前 \(x\) 足以預測未來。 Bellman equation 需要攜帶更多歷史資訊，不能只寫成 \(\EV(x)\)。
i.i.d. EV1 或適當 GEV Flat EV1 給 log-sum 與 logit；GEV 允許用 nested inclusive values。 \(\EV\) 仍可定義，但 expected maximum 通常要 numerical integration 或 simulation。
\(\beta<1\) 與有限 value 使 integrated Bellman operator 具有 contraction 性質並保證唯一 fixed point。 迭代未必收斂，lifetime value 也可能不有限或不唯一。
講義也允許 GEV/nested choice tree，使相近選項的 shocks 可以相關，例如先選 keep/purge/replace， 再在 replace 裡選車型與車齡。這時不是把所有 leaf alternatives 硬套一個 flat logit， 而是逐層使用 inclusive value；解析期望與平滑性仍然保留。

\[ q^\star=q^\star\Omega(P)Q. \]

6

需求、供給與二手車市場出清

每一個可交易的 \((j,d)\) 都有一條 excess-demand equation。

車 \((j,d)\) 的需求demand flow
\[ D_{jd}(P,q) =\Pi(j,d\mid\varnothing,P)q_{\varnothing} +\sum_{i=1}^{J}\sum_{a=1}^{\bar a} \Pi(j,d\mid i,a,P)q_{ia}. \]
經濟直覺： 第一項是目前無車者的購買流量，第二項是所有現有車主換入 \((j,d)\) 的流量。 CCP 是「每個狀態的人有多想買」，\(q\) 是「那個狀態有多少人」；兩者相乘才是市場需求量。
車 \((j,d)\) 的供給supply flow
\[ S_{jd}(P,q) = \left[1-\Pi(\kappa\mid j,d,P)\right] \left[1-\Pi(1_s\mid j,d,P)\right]q_{jd}. \]
經濟直覺： 只有目前持有 \((j,d)\)、決定不 keep、而且離手時不 scrap 的家戶，才把車送進二手市場。 報廢是退出實體車 stock，不構成另一位消費者可購買的 supply。
Excess demand 與市場出清price equation
\[ \ED(P,q)\equiv D(P,q)-S(P,q)=0. \]
經濟直覺： 若某種舊車 \(ED_{jd}>0\)，想買的人比願意賣的人多，價格需要上升； 若 \(ED_{jd}<0\)，價格需要下降。共有 \(J(\bar a-1)\) 個內生二手車價格， 也有同樣數目的市場出清方程。
Stationary equilibriumjoint consistency
\[ q^\star=q^\star\Omega(P^\star)Q, \qquad 0=\ED(P^\star,q^\star). \]
經濟直覺： 第一式讓 population distribution 隨時間不漂移，第二式讓每個二手市場沒有未滿足的買賣量。 兩式共同決定 \(q^\star\) 與 \(P^\star\)：不能先把持有分布當成固定資料，再單獨解價格。
7

持久異質性：共同價格，不同持有分布

不同消費者類型可以有不同偏好與金錢邊際效用，但在同一市場面對同一組價格。

各類型的 stationaritywithin type
\[ \forall\tau,\qquad q_\tau^\star=q_\tau^\star\Omega_\tau(P^\star)Q. \]
經濟直覺： 每一類型 \(\tau\) 都有自己的選擇機率與長期持有分布；富裕者可能集中在較新、較好的車， 貧窮者則集中在較舊車或無車狀態。
跨類型的市場出清aggregate market
\[ 0=\sum_{\tau=1}^{N}f_\tau\, \ED(P^\star,q_\tau^\star). \]
經濟直覺： 市場不要求每個 income type 自己供需平衡；富人賣出的舊車可以由窮人買走。 權重 \(f_\tau\) 把各類型的交易流加總，這正是 gains from trade 與 sorting 的來源。
交易成本的 general-equilibrium 效果： 高交易成本不只讓每個人少換車，也可能把低所得者擠出二手市場、使車更早報廢， 並讓均衡價格更接近「只有富人參與」的市場。

for each trial θ from the MLE optimizer: initialize equilibrium prices P repeat until market clearing: solve EV = Γ(EV, P; θ) compute CCPs and trade matrix Ω(P) solve q = q Ω(P) Q, with q1 = 1 evaluate ED(P, q) update P with a Newton step construct Π(x' | x, τ, θ) at equilibrium return likelihood and analytic score to optimizer

Inner DP

給定價格，把家戶當成 price taker。這一小步仍然是標準 NFXP 的 Bellman problem。

Equilibrium solver

價格不是政策輸入，而是讓所有二手車市場同時出清的未知數。

Outer estimator

參數改變偏好與交易行為，也會改變 equilibrium prices；likelihood 必須納入這條回饋。

為什麼 Newton 與 analytical derivatives 是可行性的關鍵

講義的核心計算策略，是把已算過的局部 derivative 用 chain rule 一路往外傳。

一般 Newton updateroot finding
\[ z_{k+1} =z_k-\left[\frac{\partial F(z_k)}{\partial z'}\right]^{-1}F(z_k). \]
經濟直覺： \(F(z_k)\) 告訴我們目前「不一致」多少，Jacobian 告訴我們每個未知數改一點會讓不一致如何變化。 Newton step 解一個局部線性化系統，直接選擇最可能把 residual 推回零的方向與幅度。
Bellman residual 與 Newton-KantorovichDP layer
\[ F_{EV}(EV,P)=EV-\Gamma(EV,P;\theta)=0. \]
經濟直覺： residual 是「目前猜的 lifetime value」減去「按照目前猜測重新最佳化得到的 lifetime value」。 Newton-Kantorovich 就是把一般 Newton method 用在整條 value function 上。
價格如何影響已解出的 value functionimplicit derivative
\[ \frac{dEV^\star}{dP'} = \left[I-\Gamma_{EV}\right]^{-1}\Gamma_P. \]
經濟直覺： \(\Gamma_P\) 是價格對「今天 payoff」的直接效果； \([I-\Gamma_{EV}]^{-1}\) 把這個衝擊反覆傳到所有未來期。 所以它不是普通 demand derivative，而是包含整條 lifetime adjustment 的 long-run derivative。
Stationary distribution 的 derivativeaggregation layer
\[ M(P)=\Omega(P)Q,\qquad \frac{dq}{dP'}(I-M) =q\frac{dM}{dP'}, \qquad \frac{dq}{dP'}\mathbf 1=0. \]
經濟直覺： 價格先改變 choice probabilities，再改變長期有多少人落在每個 ownership state。 最後一個 normalization 表示所有 population shares 的變化加總必須為零； 它也處理 stationary transition matrix 所帶來的奇異性。
Equilibrium price Jacobianmarket layer
\[ \frac{d\,\ED}{dP'} = \ED_P +\ED_{EV}\frac{dEV^\star}{dP'} +\ED_q\frac{dq^\star}{dP'}. \]
經濟直覺： 價格有三條效果：直接改變交易 payoff、透過 lifetime value 改變選擇、再透過長期持有分布改變市場上有哪些買方與賣方。 analytical Jacobian 把三條路徑都保留下來，Newton price solver 才能穩定而快速。

Precise starting values

先解沒有 transaction costs 的相近模型，取得價格的線性解，再用它啟動完整非線性模型。

Warm starts

相鄰的 \(\theta\) 或 Newton iterations 通常很接近，沿用上一輪 \(P,EV,q\) 可大幅減少工作。

Chain rule reuse

DP 已算出的 derivative 不丟掉，而是繼續用來組合 market Jacobian 與 likelihood score。

10

MLE：用家庭狀態轉移辨識結構參數

資料不是單純的 market shares，而是家庭從 \(x\) 到 \(x'\) 的轉移 counts。

Grouped transition likelihoodestimation
\[ L(\theta) = \sum_{\tau}\sum_{x'}\sum_x N_{x'x\tau} \log\Pi(x'\mid x,\tau,\theta). \]
經濟直覺： 若某種轉移在資料中出現 \(N_{x'x\tau}\) 次，模型就會因為給它低機率而被重罰很多次。 \(\Pi(x'\mid x,\tau,\theta)\) 結合家戶 choice 與車輛 physical transition， 而且是在 \(\theta\) 所隱含的 equilibrium \(P^\star(\theta)\) 下計算。
BHHH 的 outer-product curvatureoptimizer
\[ s_n(\theta)=\frac{\partial\log\Pi_n(\theta)}{\partial\theta}, \qquad B(\theta)=\sum_n s_n(\theta)s_n(\theta)'. \]
經濟直覺： score \(s_n\) 指出第 \(n\) 筆轉移希望參數往哪裡移；\(B\) 用 scores 的外積近似 likelihood curvature。 它避免直接計算昂貴的二階 derivative，同時利用 analytical first derivatives。
估計時不能 freeze prices。 若改變 \(\theta\) 後仍使用舊的 \(P^\star\)，score 會漏掉 \(\theta\rightarrow P^\star\rightarrow CCP\) 的 general-equilibrium channel， 得到的不是這個 structural equilibrium model 的 likelihood derivative。
11

Driving：如何把連續選擇變成可先解的靜態子問題

關鍵假設是事故與物理劣化不依賴當期行駛里程 \(x\)。

Ownership 與 driving utilitywithin-period problem
\[ \begin{aligned} u(a,x)&=u_{\text{car}}(a)+u_{\text{drive}}(a,x) +\mu[\text{net trade payoff}],\\ u_{\text{car}}(a)&=\alpha_0+\alpha_1a+\alpha_2a^2,\\ u_{\text{drive}}(a,x) &=(\gamma_0+\gamma_1a)x-\mu px+\frac{\phi}{2}x^2, \qquad \phi<0. \end{aligned} \]
經濟直覺： 車齡用 quadratic 捕捉服務品質與維修成本的非線性； 每公里 benefit 是 \(\gamma_0+\gamma_1a\)，每公里貨幣成本是 \(p\)， \(\phi<0\) 使 driving 的邊際效用遞減並保證 interior maximum。
最適行駛里程FOC
\[ x^\star(p,a) =-\frac{1}{\phi}\left[\gamma_0+\gamma_1a-\mu p\right] =d_0+d_1a+d_2p. \]
經濟直覺： driving demand 對車齡與每公里成本是線性的 reduced form。 因為 \(\phi<0\) 且 \(\mu>0\)，\(d_2=\mu/\phi<0\)：燃料或道路使用成本越高，行駛越少。
把 \(x^\star\) 代回：indirect utilitydimension reduction
\[ \begin{aligned} u\!\left(a,x^\star(p,a)\right) &= \alpha_0+\alpha_1a+\alpha_2a^2 -\frac{1}{2\phi} \left[\gamma_0+\gamma_1a-\mu p\right]^2\\ &=u_0+u_1a+u_2a^2. \end{aligned} \]
經濟直覺： 家戶先在每個 ownership state 內選最適里程，動態模型只需要帶入「已經最佳化過」的車齡效用。 因此不必把連續的 \(x\) 加進 Bellman state/action grid，計算量大幅下降。

Stage 1

用 driving data 估 \(d_0,d_1,d_2\)，取得里程對車齡與價格的 reduced-form response。

Stage 2

用 DNFXP MLE 估 \(u_0,u_1,u_2,\mu,\phi\)、交易成本與事故機率。

Stage 3

結合兩階段係數，back out \(\alpha\) 與 \(\gamma\) 等 structural parameters 做政策模擬。

為什麼需要「事故不依賴 \(x\)」？ 若開得越多會提高未來事故或劣化機率，\(x\) 就同時影響本期 utility 與未來 \(Q\)； driving 不再是靜態子問題，必須在 Bellman equation 內和換車選擇聯合求解。

反事實政策：為什麼一定要重新求均衡

降低新車登記稅會同時改變新車價格、二手價格、車隊年齡、行駛里程與稅基。

真正的 revenue-neutral constraintcounterfactual
\[ R\!\left(t_{\mathrm{reg}},t_{\mathrm{fuel}}; P^\star(t),q^\star(t)\right)=R_{\mathrm{baseline}}. \]
經濟直覺： 稅率改變後，稅基不是固定的：家庭會改變買車、換車、持有與 driving， 二手價格和車隊結構也會內生調整。只用固定稅基算出的「預期 revenue neutrality」 不等於均衡中的 realized revenue neutrality。
情境是否重求均衡模型中的意義講義結果
Naive, expected 否 假設新舊車價格同比下降，再用固定反應調 fuel tax 帳面上 revenue neutral
Naive, realized 是 把同一政策放回 equilibrium model 實際稅收約比預期低 20%
Sophisticated 是 直接在 equilibrium outcomes 上選 revenue-neutral fuel tax 較低 fuel tax 即可維持基準稅收
位於 Laffer curve 頂點右側policy diagnosis
\[ \left.\frac{dR}{dt_{\mathrm{reg}}}\right|_{\mathrm{baseline}}<0. \]
經濟直覺： 在目前高稅率附近，再提高登記稅會讓新車銷量與後續稅基萎縮得更快，總稅收反而下降。 因此降低登記稅並提高 usage tax，可能同時提高 welfare、稅收並降低 CO2； 但政策幅度必須在 general equilibrium 中決定。

常見誤解與讀模型的檢查順序

把這幾件事分清楚，DNFXP 就不會只剩下巢狀迴圈。

「家戶把價格當外生」不等於「模型價格外生」

個體 solver 中家戶是 price taker；所有家戶行為加總後，\(P^\star\) 仍由 market clearing 內生決定。

Stationarity 不等於沒有人交易

\(q_t=q_{t+1}\) 只要求 aggregate shares 不變，背後可以有大量 replacement、sale 與 scrappage flows。

\(q\) 不是隨便校準的 market share

它必須同時符合 CCP 所產生的 \(\Omega(P)\) 與物理轉移 \(Q\)，是均衡未知數的一部分。

\(q(P)\) 唯一不保證 \(P^\star\) 唯一

給定價格的 Markov chain 可有唯一 invariant distribution，但 nonlinear excess-demand system 仍可能有多個 root。

Persistent types 不各自出清

每個類型有自己的 stationary distribution，但所有類型在共同價格下加總供需，允許跨類型交易。

Counterfactual 不能只改 utility

政策改變後必須重算 \(EV^\star,\Omega,q^\star,P^\star\)；否則遺漏價格與市場組成的回饋。

用五個問題快速檢查一個 DNFXP implementation
  1. Bellman residual \(\|EV-\Gamma(EV,P)\|\) 是否足夠小？
  2. stationarity residual \(\|q-q\Omega(P)Q\|\) 與 \(q\mathbf1-1\) 是否足夠小？
  3. 每一個二手車市場的 \(\ED_{jd}\) 是否接近零，而不只是總量加總為零？
  4. outer likelihood derivative 是否包含 \(dP^\star/d\theta\) 與 \(dEV^\star/d\theta\)？
  5. 政策反事實是否重新解了整個 equilibrium，而非沿用基準價格與分布？
最後的 mental model： \(\theta\) 決定 preferences 與 technology；\(P\) 協調所有家戶的買賣； \(EV\) 讓每個家戶跨期一致；\(q\) 讓個體行為變成市場供需； DNFXP 就是不斷調整這些物件，直到「個體最適、分布穩定、市場出清」同時成立。

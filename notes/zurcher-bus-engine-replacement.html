Zurcher 的公車引擎更換問題

用一台公車看懂動態結構模型的核心直覺

Harold Zurcher 每期面對的是一個簡單但很有力的問題：這台公車引擎越跑越老， 我應該今天花大錢換新，還是再撐一期、承受更高的維修風險？

Keep: 今天省下 replacement cost 但 mileage 會繼續累積，未來 ordinary maintenance 變得更貴。
Replace: 今天付出固定大成本 但引擎狀態重置，未來從低 mileage 重新開始。

動畫直覺：mileage 上升，replacement probability 也上升

調整 \(RC\) 看 threshold 如何移動。

1. 這個模型在問什麼？

研究者看到的是一串資料：每台公車在每個月的 mileage，以及 Zurcher 當月有沒有換引擎。 研究者看不到的是 Zurcher 心裡的 replacement cost、maintenance cost function、 還有他如何把今天成本和未來成本放在一起權衡。

Dynamic structural econometrics 的目標就是把這套隱含決策規則估出來。估出之後， 我們不只是在描述資料，而是可以問反事實問題：如果換引擎成本變高，長期引擎需求會怎麼變？

2. 狀態、選擇、效用

每一期的選擇集合很小，只有 keep 或 replace。困難不在選項多，而在每個選項都會改變未來狀態。

  • \(d_t=0\)：ordinary maintenance，也就是 keep。
  • \(d_t=1\)：engine replacement。
  • \(x_t\)：上次換引擎後累積的 mileage。
  • \(\varepsilon_t(d)\)：研究者看不到、Zurcher 當期看得到的 choice-specific shock。
\[ d_t \in \{0,1\}, \qquad s_t = \bigl(x_t,\varepsilon_t(0),\varepsilon_t(1)\bigr) \] \[ U(x_t,\varepsilon_t,d_t;\theta) = \begin{cases} -RC - c(0;\theta_1) + \varepsilon_t(1), & d_t=1,\\ -c(x_t;\theta_1) + \varepsilon_t(0), & d_t=0. \end{cases} \]

3. Replacement 的力量：狀態重置

這個例子真正動態的地方在 transition。keep 的時候，mileage 從現在的 \(x_t\) 往上走； replace 的時候，下一期 mileage 從 0 附近重新開始。

所以 replacement cost 不是單純的當期固定成本，它是用今天的錢買一條比較好的未來路徑。

\[ p(x_{t+1}\mid x_t,d_t;\theta_3) = \begin{cases} g(x_{t+1}-0;\theta_3), & d_t=1,\\ g(x_{t+1}-x_t;\theta_3), & d_t=0. \end{cases} \]

讀法：replace 之後，下一期的 mileage increment 是從新引擎狀態開始抽出來的。

4. Bellman equation：今天選擇加上未來價值

\[ V(x,\varepsilon) = \max_{d\in\{0,1\}} \left\{ u(x,d;\theta_1)+\varepsilon(d) +\beta E\left[V(x',\varepsilon')\mid x,\varepsilon,d\right] \right\}. \]

這條式子的重點不是形式，而是「choice-specific value」。Zurcher 比較的是： keep 的今天成本加未來價值，對上 replace 的今天成本加未來價值。

Keep \(d=0\)

今天不用付 \(RC\)，但 mileage 繼續累積，未來維修成本可能更高。

Replace \(d=1\)

今天付 \(RC\)，但未來從低 mileage 重新開始，continuation value 可能更好。

5. Rust 的三個假設：為什麼需要？

p.7 的 AS、CI、EV1 不是只是為了讓符號漂亮，而是把原本必須在 \((x,\varepsilon)\) 上解的高維、非平滑 fixed point，改寫成只需要在 mileage \(x\) 上解的 expected value problem。p.8 的三個簡化剛好對應到這三個假設： 分離 deterministic choice-specific value、縮小 state space、再用 EV1 算出 expected maximum。

\[ V(x,\varepsilon)=\max_d\{v(x,d)+\varepsilon(d)\}, \qquad v(x,d)=u(x,d;\theta_1)+\beta EV(x,d). \] \[ EV(x,d)=E\left[V(x',\varepsilon')\mid x,d\right], \qquad \bar V(x)=\log\sum_{j\in\{0,1\}}\exp\{v(x,j)\}. \]
AS

Additive separability in preferences

為什麼需要： \(U(s_t,d)=u(x_t,d;\theta_1)+\varepsilon_t(d)\) 讓 observed part 和 unobserved shock 可以分開處理。研究者可以先算 deterministic 的 continuation value \(v(x,d)\)，最後才把當期 shock 加回去比較。

如果沒有： \(\varepsilon\) 可能和 \(x\)、\(d\) 或參數以複雜方式交互，無法把 value function 拆成「可觀察狀態的價值」加上「當期擾動」。Bellman equation 會被迫保留 \(V(x,\varepsilon)\)，估計時也更容易把 maintenance cost 和 unobserved taste 混在一起。

CI

Conditional independence

為什麼需要： CI 把 transition 拆成 \(q(\varepsilon_{t+1}\mid x_{t+1},\theta_2)p(x_{t+1}\mid x_t,d,\theta_3)\)。 也就是說，給定下一期 mileage 之後，未來 shock 不再被今天的 shock 或今天的 choice 直接預測。當期 \(\varepsilon_t\) 只影響今天的選擇，不需要成為明天的狀態。

如果沒有： unobserved shock 可能有 persistence，或今天的 shock 會改變未來 mileage process。 研究者就要追蹤 hidden state 或 posterior distribution，內層 fixed point 重新變成 高維積分問題；資料裡的 replacement 也可能同時反映暫時 shock 和持久的 bus quality， 很難用單一 mileage 狀態解釋。

EV1

Extreme value Type I shocks

為什麼需要： i.i.d. EV1 shock 在 \(\lambda=1\) 的 normalization 下，讓 \(E_\varepsilon[\max_j\{v(x,j)+\varepsilon(j)\}]\) 有 log-sum 的 closed form，也讓 choice probability 變成 logit。這是 NFXP 每次猜參數都能快速重解 Bellman fixed point 的關鍵。

這也是為什麼很多 discrete choice model 都愛用 EV1：它不一定是最真實的 shock distribution，但它把 random utility model 變成 multinomial logit，把 dynamic model 裡反覆出現的 expected maximum 變成 log-sum，讓 likelihood 平滑、估計穩定， 也避免每次都做高維 numerical integration。

如果沒有： 模型不一定錯，但 expected maximum 和 choice probability 通常沒有簡單公式， 需要 quadrature、simulation 或更大的 state space。若完全沒有 shock，決策會接近硬 threshold， likelihood 容易出現 0/1 機率，也比較難配合資料中平滑的 replacement hazard。

\[ \frac{P(j\mid x)}{P(k\mid x)} = \frac{\exp\{v(x,j)\}}{\exp\{v(x,k)\}} \]

i.i.d. EV1 的代價是 IIA：兩個選項 \(j\) 和 \(k\) 的相對 odds 不會受到其他選項影響。 在 Zurcher 的二元 keep/replace 例子裡，這比較像是 logistic smoothing 的來源； 在多選項問題裡，IIA 會變成很強的 substitution pattern 限制。

IIA 和 CI 有關係，但不是同一個假設。IIA 管的是同一期、不同 alternatives 之間的 unobserved utility 是否獨立同分布；CI 管的是跨期 transition，也就是今天的 \(\varepsilon_t\) 會不會變成明天必須追蹤的 hidden state。CI 本身不 imply IIA： shocks 可以跨期條件獨立，但同一期不同選項之間仍然 correlated。反過來，i.i.d. EV1 也不等於 CI，因為它主要規定 shock 的分布形狀和 alternatives 之間的獨立性。

一句話：EV1/i.i.d. 給 logit 與 IIA；CI 把動態問題的 state space 降下來。 Rust 把它們放在一起，是因為兩者合力讓 NFXP 可計算。

6. 為什麼會像 threshold？

如果沒有 unobserved shocks，模型通常會導出某種 threshold rule：低 mileage keep，高 mileage replace。 但真實資料中不會是硬切線，因為 \(\varepsilon_t(d)\) 讓每一期都有一些研究者看不到的特殊情況。

因此我們看到的是平滑的 hazard function：mileage 越高，replace 的機率越高。

7. EV1 shock 給我們 logit choice probability

Rust 的設定讓 \(\varepsilon_t(d)\) 是 additive 且服從 extreme value type I。 好處是不用對所有 shocks 做高維積分，choice probability 可以寫成平滑的 logit 形式。

對二元選擇來說，兩個 i.i.d. EV1 shocks 的差服從 logistic distribution， 所以 keep 和 replace 的 value difference 會直接轉成 logistic probability。

\[ P(d\mid x,\theta) = \frac{ \exp\{u(x,d;\theta_1)+\beta EV_\theta(x,d)\} }{ \sum_{j\in\{0,1\}} \exp\{u(x,j;\theta_1)+\beta EV_\theta(x,j)\} }. \] \[ P(d=1\mid x,\theta) = \Lambda\left( v_\theta(x,1)-v_\theta(x,0) \right) \]

8. NFXP：估參數時，每次都先解一次動態問題

\[ \widehat{\theta} = \arg\max_{\theta} L(\theta,EV_\theta), \qquad EV_\theta = \Gamma_\theta(EV_\theta). \]
Outer loop
猜一組參數 \(\theta\)，例如 \(RC\)、maintenance cost 斜率、mileage transition。
Inner loop
在這組 \(\theta\) 下解 Bellman fixed point，得到 \(EV_\theta\)。
Likelihood
用 \(EV_\theta\) 算 \(P(d\mid x,\theta)\)，看模型多能解釋實際 replacement decisions。
Update
調整 \(\theta\)，重複直到 likelihood 最大。

一句話：NFXP 的 nested 就是「外層估參數，內層解 Zurcher 在該參數下的最適動態決策」。

9. CPR for NFXP：SA+NK 和 analytical derivative

講義裡的 CPR Step 3 是要避免只靠 successive approximation 慢慢磨 fixed point。 先把 Bellman fixed point 改寫成 residual equation：

\[ F(\bar V)=\bar V-\bar\Gamma_\theta(\bar V)=0. \] \[ \bar V_{k+1} = \bar V_k - \left[I-\bar\Gamma_\theta'(\bar V_k)\right]^{-1} \left[\bar V_k-\bar\Gamma_\theta(\bar V_k)\right]. \]

直覺是：SA 只問「套一次 Bellman operator 會去哪裡」；Newton-Kantorovich 則問 「在目前 \(\bar V_k\) 附近，用線性近似看，要往哪個方向修正才能把 residual 推到 0」。 所以實作上不是只用 Newton，而是用 poly-algorithm：先用 SA 安全靠近 fixed point， 等 residual ratio 接近 \(\beta\) 時，再切到 NK 快速收尾。

SA
\(\bar V_{k+1}=\bar\Gamma_\theta(\bar V_k)\)。因為 \(\bar\Gamma_\theta\) 是 contraction，所以 global convergence 很穩，但只有 linear convergence： \(\|\bar V_{k+1}-\bar V^*\|\leq \beta\|\bar V_k-\bar V^*\|\)。
Switch
當 \(\mathrm{tol}_{k+1}/\mathrm{tol}_k\) 接近 \(\beta\)，代表 SA 已經進入慢速線性區。 這時繼續 SA 會很慢，尤其 \(\beta\) 接近 1。
NK
NK 在 fixed point 附近有 quadratic convergence： \(\|\bar V_{k+1}-\bar V^*\|\leq A\|\bar V_k-\bar V^*\|^2\)。 誤差會像 \(10^{-3}\to 10^{-6}\to 10^{-12}\) 一樣快速下降。

Step 4 的角色是讓 Step 3 的 Newton step 真正可靠：提供 Bellman operator 對 value function 的 analytical derivative。以 integrated value function 為例：

\[ \bar\Gamma(\bar V)(x) = \log\sum_d \exp\left\{ u(x,d)+\beta\sum_y P_d(x,y)\bar V(y) \right\}. \] \[ \frac{\partial \bar\Gamma(x)}{\partial \bar V(y)} = \beta\sum_d P(d\mid x)P_d(x,y), \qquad \bar\Gamma' = \beta\sum_d \operatorname{diag}\{P(d\mid x)\}P_d. \]

這個 derivative 的讀法很直覺：未來 state \(y\) 的 value 多一點，今天 state \(x\) 的 Bellman update 會增加多少，取決於三件事：discount factor、今天選 \(d\) 的機率、 以及選 \(d\) 後明天到 \(y\) 的 transition probability。因此 \(\bar\Gamma'\) 就是 \(\beta\) 乘上目前 policy 下的 weighted transition matrix。

一句話：Step 3 給 NFXP 快速收斂的 Newton step；Step 4 給這個 Newton step 精準的 slope。 沒有 analytical derivative，NK 會變貴、變吵，也比較難保住 quadratic convergence。

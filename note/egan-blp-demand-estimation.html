全貌：BLP 是兩層反演

先不要被公式淹沒；整套方法只是在回答「偏好如何從市占率中被辨認出來」。

一句話版本

Inner loop 對每組偏好異質性參數找出能配適市占率的平均效用； outer loop 再用經濟上的排除限制，判斷哪組偏好參數可信。

猜 θ₂ 異質性參數
解 δ(θ₂) 模型 shares = 觀察 shares
估 θ₁ 平均係數的 IV/GMM
算 ξ δ − Xθ₁
最小化 Q 讓 Z′ξ 接近 0
資料層

我們看得到

價格 p、產品特徵 x、銷量 q、市場規模 M 與市占率 s。

結構層

我們想知道

平均偏好、偏好異質性、價格敏感度、未觀察品質與替代模式。

識別層

我們額外需要

價格或產品設計的外生變化，讓需求衝擊不會被誤認成價格偏好。

為什麼不能只看「價格與銷量的相關」？

價格與數量是供需同時決定的均衡結果。高需求衝擊通常同時推高價格與銷量； 因此正相關不代表需求曲線向上，而可能只是需求曲線向外移動。

2

隨機效用模型：把選擇寫成效用最大化

離散選擇模型不直接對數量下假設，而是先描述每個人的選擇規則。

uijt = αpjt + xjt′β + ξjt + εijt
共同部分

ξjt：產品需求衝擊

同一市場內所有消費者共同面對，計量學家看不到，但廠商通常在定價時看得到。

例：品牌聲譽、服務品質、地點便利、未記錄廣告。

個人部分

εijt：私人偏好衝擊

同一產品對不同人不同，用來把確定性的效用排序轉換為選擇機率。

它不是產品層級回歸中的殘差。

將所有消費者共同的部分定義為 mean utility：

δjt ≡ αpjt + xjt′β + ξjt

消費者的問題是：

ji* = arg maxj∈{0,1,…,Jt} {δjt+εijt}
為什麼要放 outside good 並把它的效用設為 0？

所有產品效用同時加上一個常數不會改變選擇。因此資料只能識別相對效用， 不能識別絕對水準。令 δ0t = 0 是位置 normalization， 使 inside goods 的效用都解釋成「相對於不購買」。

Egan 講義 效用寫 αp，正常情況 α < 0
等價
常見 BLP 寫法 效用寫 −αp，並定義 α > 0
3

T1EV 假設如何導出 logit 機率？

封閉解不是免費的：它來自特定分配、獨立性與尺度 normalization。

假設個人偏好衝擊獨立同分配：

εijt ∼ i.i.d. Type-I Extreme Value

其累積分配函數是 F(e) = exp{−exp(−e)}。產品 j 被選擇的事件是：

Pijt = Pr ( δjt + εijt ≥ δkt + εikt , ∀k )
展開：從最大效用事件積分到 logit 公式

先令 Vj = δjt，並給定 εj = e。產品 j 勝過產品 k 等價於：

εk ≤ e + Vj − Vk

由跨產品獨立性，給定 εj = e 時，同時勝過所有產品的機率可相乘：

Pj = ∫ f(e) ∏k≠j F(e + Vj − Vk) de

代入 T1EV 的 F 與密度 f，被積分式化為：

e−e exp{−A e−e},   A = e−Vj∑ℓeVℓ

令 y = e−e，積分等於 1/A，因此：

Pj = eVj / ∑ℓeVℓ
Pijt = exp(δjt) 1+ ∑ℓ=1Jt exp(δℓt)
得到什麼

封閉解

不必做多維數值積分，就能直接算個人選擇機率。

付出什麼

i.i.d. 誤差

未觀察偏好在產品間沒有相關性，埋下 IIA 問題。

還 normalization 什麼

效用尺度

資料只識別所有效用係數相對於 ε 尺度的比率。

4

從個人機率到市占率，再到 Berry inversion

simple logit 最漂亮的一步：非線性 choice probability 可以被解析反演。

市場內有大量消費者時，依大數法則，選擇產品 j 的人口比例會接近個人選擇機率。 因此：

sjt = exp(δjt) 1+ ∑ℓ=1Jt exp(δℓt)

寫出 outside share

s0t = 1 / Dt，其中 Dt = 1 + ∑ℓexp(δℓt)。

inside share 除以 outside share

共同分母完全消掉：sjt/s0t = exp(δjt)。

取對數

得到解析反演：δjt = log(sjt) − log(s0t)。

代回平均效用

把反演後的 δ 寫成價格、特徵與未觀察品質的回歸方程。

logsjt − logs0t = αpjt + xjt′β + ξjt

Berry（1994）simple-logit demand equation。

為什麼這個反演如此重要？

左側完全由 observed shares 決定，原本的非線性聯立市占率方程因此變成線性回歸。 BLP inner loop 就是把這個解析反演推廣到有 random coefficients、無封閉反解的情況。

補充：為什麼也可以用 market fixed effects？

直接取 inside share 的對數：

log sjt = αpjt + x′jtβ + ξjt − log Dt

−log Dt 對市場 t 內所有產品都相同， 因此可以由 unrestricted market fixed effect 吸收。但這只處理共同分母； 不會處理價格與 ξ 的相關。

5

價格內生性：為什麼 OLS 不是需求曲線？

廠商看得到需求衝擊再定價，使高品質、高價格與高市占率同時出現。

Demand shock

ξjt 高

消費者在相同價格下更願意選產品 j，需求曲線向外移動。

Firm response

廠商提高 pjt

若廠商知道 ξ 很高，最適價格通常也較高，因此 Cov(p, ξ) > 0。

展開：OLS 偏誤的方向

將產品特徵 x partial out，OLS 價格係數的機率極限為：

plim α̂OLS = α + Cov(p̃, ξ) / Var(p̃)

講義寫效用為 αp，所以真實 α 通常小於 0。若 Cov(p, ξ) > 0， 偏誤為正，估計值就會「比較不負」。

真實 α = −2   →   OLS α̂ = −0.8

因此估計出的價格敏感度 −α 太小，看起來消費者比實際上更不在乎價格。

供需圖的訊息

單一均衡點不能告訴我們觀察到的是需求還是供給。若有只移動供給的變數， 多個由供給位移造成的均衡點才會沿著同一條需求曲線排列。

有效工具變數的兩個條件

1 · Relevance

工具必須預測價格

Cov(zjt, pjt | xjt) ≠ 0

2 · Exogeneity

工具不能隨需求衝擊變動

E[zjtξjt] = 0

zownjt = ∑k≠j, f(k)=f(j)xkt

競爭者產品越接近 j，廠商通常越難維持高 markup；自家相似產品則會造成內部蠶食。 因此其他產品的特徵在控制 xjt 後仍能預測價格。 但工具有效需要其他產品特徵與 ξjt 正交。

6

Simple logit 的彈性、IIA 與紅巴士／藍巴士

simple logit 好算，但替代模式主要由市占率決定，而不是產品相似性。

展開：own-price 與 cross-price elasticity 推導

因為 sj = exp(δj)/D，所以：

∂sj/∂δj = sj(1−sj)

又因講義的 ∂δj/∂pj = α，所以：

∂sj/∂pj = αsj(1−sj)
ηjj = (∂sj/∂pj)(pj/sj) = αpj(1−sj)

若 k ≠ j，改變 pk 只透過共同分母影響 sj：

∂sj/∂pk = −αsjsk
ηjk = −αskpk

α < 0 時，own elasticity 為負，cross elasticity 為正。

限制出現在 cross elasticity

對固定的漲價產品 k，所有目的地產品 j 的 cross elasticity 都是 −αskpk。它不看產品 j 是否和 k 相似。

IIA 的代數

sj sk = exp ( δj − δk )

加入或刪除第三個產品，不會改變既有兩產品的 share ratio。

原本

汽車 C ＋ 紅巴士 R

若兩者效用相同，simple logit 給 sC = sR = 1/2。

加入完全相同的藍巴士

模型把 C、R、B 各給 1/3

合理直覺通常是汽車仍有 1/2，原本的巴士乘客再由紅、藍各分一半。

問題的來源

每新增一個產品，i.i.d. logit 就新增一個獨立的 ε 抽樣機會。 即使藍巴士在可觀察特徵上是紅巴士的複製品，模型仍把它視為新的獨立效用來源。 BLP 的目的就是讓相似產品的未觀察選擇傾向透過共同偏好係數產生相關。

7

BLP：把偏好係數變成消費者特有

random coefficients 讓替代關係取決於「哪些人同時喜歡哪些產品」。

uijt = xjt′ βi − αi pjt + ξjt + εijt

一個方便的異質性參數化是：

βi = β + Πdi + Σνi,   νi ∼ N(0, I)
αi = α + π′pdi + σ′pνi
Observed heterogeneity

di：人口特徵

所得、年齡、財富等可直接讓產品偏好與價格敏感度因人而異。

Unobserved heterogeneity

νi：隨機偏好

即使人口特徵相同，消費者仍可能有不同的特徵偏好。

將效用拆成三塊：

δjt = x′jtβ − αpjt + ξjt

所有消費者共同的 mean utility。

μijt = x′jt(Πdi + Σνi) − pjt(π′pdi + σ′pνi)

因人口特徵與 taste draws 而異的個人偏離。

uijt = δjt + μijt + εijt
部分 誰共享？ 估計中的角色
δjt 同一市場所有消費者 inner loop 從 observed shares 反演；含未觀察品質 ξ。
μijt 因消費者而異 產生異質性、產品相似性與較真實的替代模式。
εijt 個人—產品特有 保留 conditional logit 封閉解。
為什麼相似產品會變成近替代品？

若兩個 ETF 都追蹤同一指數，對該指數係數很高的消費者會同時給兩者較高的 μ。 當其中一個漲價，這群人自然較可能轉向另一個；替代關係因此由產品特徵與偏好分布共同決定。

8

條件 logit 機率與市場積分

給定一個人的偏好，他仍是 logit；市場 share 則是把所有類型的人平均起來。

固定 di、νi 與 δ 後，ε 仍為 T1EV，因此：

Pijt = exp ( δjt + μijt ) 1+ ∑ℓ=1Jt exp ( δℓt + μiℓt )

市場 share 是對人口偏好分配積分：

sjt (δ,θ2) = ∫ Pijt (δ,θ2) dF (di,νi)
為什麼現在沒有 simple-logit 的封閉反演？

分母中的 μ 對每個人不同；市場 share 是許多不同 logit 分母的平均， 不能再用 sj/s0 直接消去共同分母。

用 simulation 近似積分

s^jt = 1R ∑r=1R Prjt
  • 抽取人口特徵與標準常態 taste draws。
  • 用同一組 draws 貫穿所有 optimizer iterations。
  • 可用低差異序列減少 simulation noise。
  • 用 log-sum-exp 避免 exponentials overflow。
參數化提醒

可以令 ν ∼ N(0, I) 並估計 covariance factor Σ；也可以讓 ν 本身有 covariance Ω。 兩者若同時完全自由會有尺度冗餘。實作通常固定 ν 為標準常態，估計 Σ 的 Cholesky factor。

9

Inner loop：contraction mapping

固定異質性 θ₂，找出能讓模型市占率等於觀察市占率的 δ。

sobs = smodel (δ,θ2)

標準更新為：

δj(r+1) = δj(r) + logsjobs − logsjmodel (δ(r),θ2)
模型 share 太低

提高 δj

log sobsj − log smodelj > 0

模型 share 太高

降低 δj

log sobsj − log smodelj < 0

展開：為什麼 fixed point 等於 share matching？

定義：

Tj(δ) = δj + log sobsj − log smodelj(δ)

若 δ* 是 fixed point，則 Tj(δ*) = δ*j。兩邊消去 δ*j：

log sobsj − log smodelj(δ*) = 0

因此 sobsj = smodelj(δ*)；反方向也成立。

進階：outside good 為什麼幫助 contraction 收斂？

個人 logit derivative 為：

∂Pij/∂δk = Pij[1{j=k} − Pik]

因此 contraction mapping Jacobian 的元素為：

∂Tj/∂δj = ∫P2ijdF / sj
∂Tj/∂δk = ∫PijPikdF / sj,   k ≠ j

一列元素總和是：

∑k=1J∂Tj/∂δk = ∫Pij(1−Pi0)dF / sj < 1

只要 outside-good probability 為正，在標準正則條件及適當有界區域內， mapping 的變動幅度小於 δ 本身的變動幅度，重複更新便會收斂到唯一解。

實作起點與停止條件

常用 simple-logit inversion δ(0)jt = log sobsjt − log sobs0t 初始化。逐市場更新，直到最大 share error 或最大 δ 更新量低於容忍值。

10

Outer loop：GMM 如何選出 θ？

inner loop 對每個 θ₂ 都能配適 shares；真正區分參數的是工具變數矩條件。

最容易漏掉的識別觀念

「市占率配適得很好」不能證明 θ₂ 正確，因為每一組 θ₂ 都可以搭配另一組 δ 完全配適市占率。 θ₂ 是靠錯誤參數所反演出的 ξ 會與 Z 系統性相關而被排除。

ξ(θ) = δ(θ2) − Xθ1
gN(θ) = 1N Z′ξ(θ) , θ^ = arg minθ gN(θ) W gN(θ)

更精確地說，objective 是 gN(θ)′WgN(θ)。

展開：線性參數 θ₁ 如何 concentrated out？

固定 θ₂ 後，inner loop 已給定 δ(θ₂)。考慮：

Q = (δ − Xθ1)′ZWZ′(δ − Xθ1)

對 θ₁ 微分並設為零：

X′ZWZ′(δ − Xθ1) = 0

得到：

θ̂1(θ2) = (X′ZWZ′X)−1X′ZWZ′δ(θ2)

因此 optimizer 只搜尋非線性 θ₂；每次自動用 IV/GMM 解平均係數 θ₁， 再計算 ξ = δ − Xθ̂₁。

若 θ₂ 正確

ξ 不應被 Z 預測

有效工具只移動價格或競爭情況，不直接移動需求衝擊。

若 θ₂ 錯誤

反演 δ 會扭曲

模型會把錯誤的替代模式塞進 ξ，使 Z′ξ 出現系統性關係。

GMM 做什麼

讓 moments 最接近 0

在工具可信的前提下，選出最符合排除限制的偏好參數。

11

完整估計演算法：從資料到參數

把前面所有數學整理成可以逐項檢查的操作順序。

定義市場、choice set 與 outside good

計算 sjt = qjt/Mt 及 s0t。這一步決定需求的經濟母體。

準備 X、價格與 Z

區分可視為外生的特徵、需要 instrument 的價格或內生特徵，並加入合理 fixed effects。

建立模擬消費者

抽取人口特徵與 ν，固定 draws，讓不同參數下的 objective 可平滑比較。

猜一組 θ₂

θ₂ 包含 demographic interactions、random-coefficient standard deviations 與 correlations。

逐市場執行 inner loop

用 contraction mapping 找 δ(θ₂)，直到模型 shares 與 observed shares 一致。

concentrate out θ₁

將 δ(θ₂) 視為 dependent variable，以 IV/GMM 求平均價格與特徵係數。

恢復 ξ 並計算 GMM objective

計算 ξ = δ − Xθ̂₁、g = Z′ξ/N 與 Q = g′Wg。

optimizer 更新 θ₂

回到 inner loop，直到 objective 與參數收斂；之後可進行 second-step GMM。

計算標準誤與診斷

考慮 market clustering、simulation、weighting matrix、工具強度與 numerical tolerance。

Inner 與 outer loop 的分工

Inner loop 是 accounting：找到足以解釋觀察 shares 的產品平均效用。 Outer loop 是 identification：判斷這些平均效用能否由合理偏好與外生需求衝擊構成。

12

估計後：異質彈性、WTP、markup 與福利

BLP 的價值不只在配適，而是建立可用於反事實的需求系統。

BLP 價格 derivatives

採常見寫法 uij = … − αipj + εij，且 αi > 0：

Own derivative

∂sj/∂pj = −∫αiPij(1−Pij)dFi

Cross derivative, k ≠ j

∂sj/∂pk = ∫αiPijPikdFi

積分中的 PijPik 衡量同一消費者是否同時把 j 與 k 視為有吸引力。 因此 cross elasticity 現在會依產品配對而不同。

Willingness to pay

講義寫效用為 u = αp + βx + …、α < 0。保持效用不變：

du = α dp + β dx = 0   ⇒   WTP = dp/dx = −β/α

多產品廠商的 markup

廠商 f 的利潤為：

πf = M∑k∈Jf(pk−ck)sk(p)

產品 j 的定價一階條件：

sj + ∑k∈Jf(pk−ck)∂sk/∂pj = 0

定義 ownership-adjusted derivative matrix：

Δjk = −1{j,k 同公司} ∂sk/∂pj
p − c = Δ−1s   ⇒   c = p − Δ−1s
需求估計不等於完整合併模型

要預測合併後的內生價格，還必須指定供給端競爭方式、ownership、邊際成本與成本是否因合併改變。 需求端只提供價格改變時消費者如何重新配置。

常見 counterfactual

Merger

改 ownership matrix，重解價格 FOCs。

Entry / Exit

改 choice set，重新計算 shares 與 welfare。

Product design

改產品特徵，模擬需求與定價。

Policy

改稅、費用或監管成本，重算市場均衡。

識別與實作檢查清單

模型能跑完不代表估計可信；以下問題應在看結果前先回答。

問題 為什麼重要？ 應檢查什麼？
零市占率 log share 不存在；標準 BLP 預測所有可選產品 share 為正。 市場是否太細、產品是否應合併、是否需要 sampling model。
outside share 接近 0 δ 水準很大，contraction 可能變慢且結果對市場規模敏感。 市場規模定義、數值容忍值、share floors。
價格工具弱 平均價格係數與 random coefficients 可能很不穩定。 first stage、不同工具集合、敏感度與經濟 relevance。
產品特徵內生 廠商可能根據預期需求選品質、地點、規格與進入。 哪些 x 可合理視為 predetermined；是否也需 instruments。
θ₂ 識別弱 shares 對每組 θ₂ 都可由 δ 配適，僅靠 aggregate moments 可能不足。 市場產品組合變化、demographics、micro moments、profile objective。
simulation noise objective 抖動會讓 optimizer 誤判 gradient 與 convergence。 固定 draws、draw 數、低差異序列與重複估計。
數值收斂 optimizer convergence 不保證每個 inner loop 已精確收斂。 最大 share error、δ update、不同初值與 gradient。
供給端假設 markup 與 merger price 取決於定價競爭方式。 Bertrand 是否合理、ownership、成本與效率假設。
Micro moments 為什麼有用？

例如「高所得投資人比較常選低費用 ETF」或「某年齡層偏好特定通路」， 直接把消費者特徵與選擇的關係帶進估計，往往比只靠 aggregate shares 更能識別 Π、Σ 與隨機價格係數。

一頁速查表

讀完後，只要能從上往下重新說一次，就已經掌握 demand-side BLP 的骨架。

步驟 核心式子 為什麼成立？
1. 效用 uij = δj + μij + εij 把共同平均效用、系統性異質性與個人產品衝擊分開。
2. 個人機率 Pij = exp(δj+μij)/Di 條件在個人偏好後，ε 仍是 i.i.d. T1EV。
3. 市場 share sj = ∫PijdFi 市場 share 是人口中各類型選擇機率的平均。
4. Inner loop δ ← δ + log sobs − log smodel fixed point 等價於 model shares = observed shares。
5. Demand shock ξ = δ(θ₂) − Xθ₁ 平均效用扣除可觀察的平均偏好後，剩下未觀察品質。
6. Moments g(θ) = Z′ξ(θ)/N 有效工具與需求衝擊正交。
7. Outer loop minθ g(θ)′Wg(θ) 錯誤偏好參數會使反演 ξ 與工具系統性相關。
8. Counterfactual 重新計算 P、s；必要時重解供給 FOCs 結構參數被假定在政策或市場環境改變後仍保持穩定。
最後的記憶句

Simple logit：用 log share difference 解析反演 δ，但替代模式受 IIA 限制。
BLP：用 random coefficients 改善替代模式；inner loop 配適 shares， outer loop 用 IV/GMM 識別偏好。

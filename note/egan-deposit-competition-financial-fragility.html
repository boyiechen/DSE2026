Deposit Competition and Financial Fragility

Mark Egan、Ali Hortaçsu 與 Gregor Matvos 把 bank-run theory 變成可估計的產業均衡模型： 未保險存款人會因違約風險撤資，撤資又削弱銀行獲利與償付能力。 真正的問題不是「run 在理論上能否發生」，而是資料估出的力量是否大到足以形成自我實現的壞均衡。

作者：Mark Egan、Ali Hortaçsu、Gregor Matvos 樣本：16/20 家最大美國商業銀行，2002–2013 核心方法：Logit deposit demand + IV + structural calibration 原始 PDF：05.Egan/egan_deposit_competition.pdf

未保險存款人承擔損失，因此將 perceived default probability 放進選擇效用。

Demand 未保險存款流失

銀行可提高利率留住資金，但更高資金成本也會壓低利潤。

存款量與利差共同決定銀行願意用多少股東資金填補當期 shortfall。

Solvency 違約門檻提高

較小的資產報酬衝擊就足以觸發 default，實際違約機率上升。

一分鐘摘要

論文把「存款競爭」和「銀行 solvency」放進同一個 fixed-point 問題。

核心研究問題

未保險存款人究竟多在意銀行違約？這個需求反應是否強到能讓悲觀信念自行實現， 使原本相同的資產 fundamentals 同時存在低違約與高違約均衡？

−0.36 未保險存款對 default risk 的估計彈性。
≈ 0 受保險存款對 default risk 的 placebo 反應，不顯著。
≈ 48–56% 五大銀行各自存在的壞均衡中，單一銀行 risk-neutral default probability。
31% 不知道 equilibrium selection 時，maximin planner 的資本要求。
Demand fact

未保險存款人會跑

在控制利率、銀行與季度效果並使用 IV 後，較高違約風險顯著降低未保險存款需求。

Equilibrium fact

壞均衡真的存在

估計出的需求與銀行技術足以支持個別大銀行的 run-like 高違約均衡。

Historical reading

危機期間仍相對「好」

2008 年觀察到的五大銀行 default probabilities 位於相對好的均衡，而不是最壞 fixed point。

最重要的經濟直覺

銀行脆弱性不是只來自 interbank loans 或共同持有資產。 即使銀行之間沒有直接信用曝險，只要它們競爭同一批存款，某家銀行的信念與資金流失就會改變所有銀行的 shares、rates 與 profits。

1

問題與貢獻：從「可能」走到「量化」

理論早已知道 bank run 可能發生；本文問的是這個機制在美國大型銀行資料中有多大。

美國商業銀行約 75% 的資金來自 deposits，講義指出其中約一半未受保險。 未保險存款人面臨本金損失，因此會把銀行 solvency 當成產品特徵；受保險存款人則由保險制度隔離。

ρ ↑預期違約風險上升
sN ↓未保險存款撤出
profit ↓資金量與利差惡化
R̄ ↑更容易選擇 default
actual ρ ↑悲觀信念被驗證
本文把三條文獻線接在一起
元件 放進模型的內容 為什麼必要？
Bank-run theory run-prone uninsured depositors、endogenous default。 建立信念、撤資與 solvency 的正回饋。
Industrial organization 差異化銀行、logit demand、寡占利率競爭。 存款不是同質資金；branch、service 與 relationships 會產生 market power。
Structural empirical work 用 IV 估需求，再用銀行最適化條件校準技術參數。 把「可能擠兌」變成可做 equilibrium search 與政策反事實的量化模型。
這不是傳統的純粹 sunspot run 模型

每家銀行都有資產報酬風險、長期債券 coupon 與差異化存款需求。 多重均衡來自 rational beliefs 與 endogenous balance-sheet outcomes 的 fixed point， 但均衡結果仍受實際資產與市場參數約束。

2

時序與均衡：誰先做什麼？

時序決定哪些是策略、哪些是信念，以及 default 為何在資產報酬實現後才發生。

銀行設定兩種存款利率

銀行 k 分別選擇 insured rate iIkt 與 uninsured rate iNkt。

存款人選擇銀行

考慮利率、銀行服務；未保險存款人還考慮 perceived default probability ρkt。

資產報酬 Rkt 實現

銀行將存款投資於資產，面對 normally distributed stochastic return。

股東選擇償付或 default

若填補當期 equity shortfall 的成本大於繼續經營價值，有限責任股東放棄銀行。

Pure-strategy Bayesian Nash equilibrium

  • 銀行選擇使自身價值最大的 insured 與 uninsured rates。
  • 存款人在給定 rates、services 與 beliefs 下最大化效用。
  • 資產報酬實現後，銀行最適地決定 default 或繼續經營。
  • 存款人的違約信念等於模型實際產生的 default probability。
Stationary simplification

講義假設資產報酬 shocks i.i.d.、市場參數不變、銀行在 bankruptcy 後保留相同 capital structure。 這讓 continuation value 可由單一 stationary value 表示，也使均衡搜尋可行；代價是忽略危機中資產與融資結構的持續調整。

3

存款需求：安全性也是銀行產品特徵

insured 與 uninsured demand 的唯一關鍵差異，是誰承擔銀行 default loss。

Uninsured deposits
uNjkt = αNiNkt − γρkt + δNk + εNjk

高利率提高效用；高違約機率降低效用；δNk 表示銀行服務與品牌。

Insured deposits
uIjkt = αIiIkt + δIk + εIjk

存款保險移除個人損失，因此效用中沒有 −γρ；這也提供漂亮的 placebo group。

參數 經濟意義 較大時代表
αIinsured deposit 對利率的半彈性尺度受保險存款更會追逐高利率
αNuninsured deposit 對利率的半彈性尺度銀行必須更積極用利率留住未保險資金
γ未保險存款對 default risk 的敏感度信念—撤資—solvency 回饋更強
δgk銀行服務品質、branch network、品牌與關係價值銀行可用非價格特徵吸引存款

若 ε 為 i.i.d. T1EV，市場占有率為：

sIkt = exp(αIiIkt + δIk) / ∑ℓexp(αIiIℓt + δIℓ)
sNkt = exp(αNiNkt − γρkt + δNk) / ∑ℓexp(αNiNℓt − γρℓt + δNℓ)
展開：利率如何改變 own-bank share？

Logit share 對本行利率的 derivative 是：

∂sgk/∂igk = αgsgk(1−sgk),   g ∈ {I,N}

若銀行 share 接近 1，額外加息能吸引的新存款很少；若 α 高，存款人對利率敏感， 小幅加息就能帶來較多資金。這個 derivative 稍後直接進入銀行的 deposit-rate FOC。

存款保險的雙面性

它讓 insured deposits 不會因銀行風險撤出，提供穩定 funding anchor； 但也使 insured depositors 不監督風險，預期損失可能轉由 FDIC 承擔。

4

銀行資產負債表：「生產」存款利差

銀行向存款人購買資金、投資於資產，再決定是否值得用 equity 填補低報酬狀態。

定義銀行 k 的兩類存款量：

DIkt = MIsIkt,   DNkt = MNsNkt

每單位存款投資後得到隨機資產報酬：

Rkt ∼ N(μk, σk)
Asset side

μk、σk

平均資產報酬與報酬風險；σ 同時影響 default tail 與有限責任的 option value。

Deposit costs

iI、iN、ck

利息是直接 funding cost；insured deposits 另有非利息成本 c，例如服務與保險相關成本。

Long-term obligation

bk

每期需支付的長期債務 coupon，使低資產報酬狀態產生 equity shortfall。

扣除存款利息與 insured non-interest cost 後，當期存款利潤為：

πk(R) = DIk(R − ck − iIk) + DNk(R − iNk)

要支付 coupon bk 後，股東需要填補：

Shortfallk(R) = bk − πk(R)
為什麼 deposits 既能穩定銀行，也能讓銀行脆弱？

多一單位存款通常帶來正利差，因此提高 profit 與 franchise value； 但存款也是到期需償還的 debt。當未保險存款撤出，銀行不只失去資金量， 還可能必須提高利率保留剩餘資金，雙重壓縮 continuation value。

5

Default threshold：股東何時選擇放棄？

有限責任把銀行 equity 變成資產報酬上的選擇權；低於某門檻就不再填補 shortfall。

令 Ek 為繼續經營的 equity value。銀行 default 的條件是：

Shortfallk(Rkt) > Ek/(1+r)

填補今天資金缺口的成本，大於保住未來 franchise value 的現值。

因為 shortfall 隨 R 單調下降，存在唯一門檻 R̄k： R < R̄k 時 default。

ρk = Pr(Rk < R̄k) = Φ[(R̄k−μk)/σk]

定義 standardized threshold：

zk = (R̄k−μk)/σk = Φ−1(ρk)

門檻的 indifference condition

bk − DIk(R̄k−ck−iIk) − DNk(R̄k−iNk) = Continuation Valuek
展開：為什麼 continuation value 出現 inverse Mills ratio？

若銀行存活，表示 R ≥ R̄。Normal distribution 的 truncated expectation 為：

E[R | R ≥ R̄] = μ + σλ(z)

其中 λ(z) = φ(z)/[1−Φ(z)] 是 inverse Mills ratio。因此存活狀態中超過 default threshold 的預期報酬為：

E[R−R̄ | R ≥ R̄] = μ−R̄ + σλ(z)

乘上總存款、存活機率並折現，得到講義中的 continuation value：

Ek/(1+r) = [(DIk+DNk)/(1+r)] [1−Φ(zk)] [μk−R̄k+σkλ(zk)]
Limited-liability term 的直覺

Equity 只保留存活時的上行報酬，低於 R̄ 的下行部分由 creditors、deposit insurer 或 resolution process 承擔。 因此銀行股東評價一單位資產時，看的是 μ + σλ(z)， 而不只是 unconditional mean μ。這使風險 σ 具有 option value，也帶來典型 risk-shifting 力量。

6

存款利率競爭：銀行為什麼不把全部資產收益付給存款人？

差異化服務創造 market power，使銀行能以低於存款邊際價值的利率取得資金。

給定最適 default threshold，使用 envelope theorem，利率一階條件可寫成：

Insured FOC
μk + σkλ(zk) − ck − iIk = 1 / [(1−sIk)αI]
Uninsured FOC
μk + σkλ(zk) − iNk = 1 / [(1−sNk)αN]
展開：FOC 的經濟推導

將一單位存款在 equity 眼中的邊際價值記為 m。忽略共同常數，銀行從某類存款得到：

Π(i) = D(i)[m − i]

提高利率有兩個效果：

  1. Extensive margin：提高 share，吸引更多 deposits。
  2. Infra-marginal cost：所有既有 deposits 都要支付更高利率。

一階條件：

D′(i)[m−i] − D(i) = 0

因 logit demand 有 D′(i)/D(i) = α(1−s)，所以：

m − i = D/D′ = 1/[α(1−s)]

insured deposits 的 m 要扣除 c；uninsured deposits 沒有該項。 講義把右側稱為 markup。從銀行「購買 funding」的觀點，也可以稱為相對於存款邊際價值的 markdown。

α 大

存款人較 price-sensitive

右側 wedge 小，競爭把更多資產收益 pass through 給存款人。

s 接近 1

銀行較有市場力量

既有客戶基礎大、邊際加息帶來的新 share 少，銀行可支付較低利率。

σλ(z) 大

有限責任提高 equity-side return

股東只保留存活狀態的上行報酬，資產風險提高其條件邊際收益。

為什麼 envelope theorem 很重要？

利率會影響 deposits，進而可能改變最適 R̄；但在最適 default boundary， 邊際改變 threshold 的一階價值為零。這讓 rate FOC 可聚焦在存款量與利率的直接效果， 並產生可用於 calibration 的簡潔 wedge 公式。

為何出現多重均衡？

違約信念既是 uninsured demand 的投入，也是銀行 balance sheet 最終產生的結果。

相信 ρ 高−γρ 降低 uninsured utility
資金流失／加息sN 下降或 iN 上升
franchise value 降低少量與薄 margin 都壓低 equity value
R̄ 上升股東較早選擇 default
模型 ρ 上升實際 default probability 驗證信念

均衡要求：

perceived ρk = Φ[(R̄k(s(ρ,i),i)/σk) − μk/σk] = actual ρk
Good equilibrium

低風險信念自我實現

uninsured deposits 穩定、funding cost 低、continuation value 高，銀行願意承受較低 R 而不 default。

Bad equilibrium

run-like 信念自我實現

撤資與高利率壓低銀行價值，使 default threshold 升高，原先悲觀的違約信念變成正確。

什麼決定回饋是否夠強？
  • γ：存款人對 default risk 是否敏感。
  • αN：銀行能否用加息有效抵銷撤資。
  • uninsured funding share：run-prone funding 在 balance sheet 中多重要。
  • μ、σ、b、capital：銀行距 default boundary 有多遠。
  • 銀行間替代：流出的 deposits 會流向哪些競爭者，以及對其 rates 和 profits 的影響。
為什麼沒有 interbank credit exposure 仍有 contagion？

銀行在同一 differentiated-deposit market 中互為替代品。 一家銀行的 risk belief 改變會重新分配所有銀行 shares，促使競爭者調整 rates； 這些變化再進入每家銀行的 profit、continuation value 與 default boundary。

8

Demand identification：風險敏感度不是相關係數

服務品質同時影響 deposits 與 solvency，直接回歸會把銀行變差誤認成 depositors 害怕 default。

核心 endogeneity

服務品質下降資料看不到的 ξkt 變差
deposit demand ↓即使 depositor 不在意 default
bank profit ↓funding franchise 變弱
default risk ↑CDS-implied ρ 上升
負相關出現但未必是 γ 的因果效果

選定一家 reference bank 0，將其 share 與產品特徵相除／相減後， demand inversion 可概念化為：

log(sNkt/sN0t) = αN(iNkt−iN0t) − γ(ρkt−ρ0t) + Bank FE + Quarter FE + ξ̃Nkt
log(sIkt/sI0t) = αI(iIkt−iI0t) + Bank FE + Quarter FE + ξ̃Ikt

這裡的 0 是 normalization 用的 reference bank，不是額外假設一個「不存款」outside good。

為什麼 insured deposits 是有力 placebo？

若同一個 default-risk instrument 也顯著降低 insured deposits， 可能表示工具仍在捕捉銀行服務惡化或其他共同需求衝擊。 模型預測 insured depositors 不承擔 default loss，因此其 γ 應接近 0。

Placebo 通過不等於 exclusion 自動成立

insured 與 uninsured 客群可能使用不同服務、擁有不同資訊，或受到不同 balance-sheet shocks 影響。 Placebo 提高可信度，但工具有效仍需經濟論證。

經濟讀法

uninsured depositors 對利率的估計反應比 insured depositors 小， 但會因 solvency risk 撤資。這表示銀行不能只靠小幅加息完全中和風險疑慮； γ 相對於 αN 的大小正是 run feedback 能否強到形成多重均衡的關鍵。

銀行參數 calibration：三組最適條件解三個 unknowns

需求估計提供 α、γ 與 shares；銀行 FOCs 和 default boundary 再反推出 c、σ、μ。

輸入資料

Demand estimates、insured/uninsured market shares、兩類 deposit rates、 CDS-implied default probability、長期債務 coupon 與 balance-sheet quantities。

用兩個 rate FOCs 的差識別 ck

共同的 conditional asset return μ+σλ(z) 被消掉，只留下 insured 相對 uninsured 的 non-interest cost。

用 default-boundary indifference 識別 σk

觀察 ρ 便知道 standardized threshold z；shortfall = continuation value 將 σ 單獨釘住。

用 uninsured rate FOC 恢復 μk

已有 σ、z、αN、share 與 rate，平均資產報酬成為剩餘 unknown。

Step 1：非利息成本 ck

將兩個 FOC 相減，得到：

ck = [iNk + 1/((1−sNk)αN)] − [iIk + 1/((1−sIk)αI)]

括號內各自是「觀察利率 + 因 market power 留下的 wedge」， 理論上都應等於該類 deposit 的邊際價值；兩者差異就是 insured-specific cost。

Step 2：資產報酬波動 σk

由觀察到的 default probability：

zk = Φ−1(ρk)

Continuation value 可以寫成：

CVk = σk[(DIk+DNk)/(1+r)](1−ρk)[−zk+λ(zk)]

而 insured FOC 讓 threshold margin 化為：

R̄k−ck−iIk = 1/[(1−sIk)αI] + σk[zk−λ(zk)]

代回 shortfall-at-threshold = continuation-value 方程，即可對每家銀行解 σk。

Step 3：平均資產報酬 μk

重排 uninsured FOC：

μk = iNk − σkλ[Φ−1(ρk)] + 1/[(1−sNk)αN]

觀察到的 uninsured rate 加上 bank market-power wedge，等於 equity-side conditional asset return； 再扣除 limited-liability option term，就得到 unconditional mean μ。

Estimation 與 calibration 的區分

α、γ 由消費者需求與 IV variation 識別；μ、σ、c 則依賴銀行最適化與分布假設， 是由模型 FOCs 精確反推。後者的可信度更直接依賴 Bertrand-style rate setting、 normal returns、stationarity 與 default-value equation。

其他均衡有多壞？

固定估計出的 fundamentals 與 preferences，只改 beliefs、shares、rates 與 default probabilities，搜尋其他 fixed points。

13

資本要求與政策：最大的難題是 equilibrium selection

政策不只改變單一均衡內的 default risk，也可能改變壞均衡是否存在與好壞均衡之間的距離。

Capital requirements

增加 loss-absorbing equity，改變 default threshold 與 equilibrium set。

Deposit insurance

降低 γ channel，但可能增加 FDIC exposure 與 moral hazard。

Interest-rate limits

限制銀行用高 rates 搶救 funding，同時改變競爭與 risk-taking。

Risk limits

直接約束 σ 或 risky-asset choice，降低 tail default probability。

Stability 圖的讀法

講義同時畫出 best 與 worst equilibrium 的 mean risk-neutral default probability。 best equilibrium 幾乎保持低風險；worst equilibrium 在低資本區間非常高，之後隨 capital requirement 增加而下降。 曲線在低資本處不單調，提醒我們政策會改變整個 equilibrium set，而不只是機械降低 leverage。

Welfare 圖的讀法

作者把 consumer surplus、annualized equity value 與 FDIC expected costs 合併。 best equilibrium welfare 接近或略高於基準；worst equilibrium 明顯較差， 中等資本要求能改善最壞結果，但過高要求又帶來 funding、competition 或 equity 成本。

為什麼無法直接取 expected welfare？

模型找到多個均衡，卻沒有提供「每個均衡會以多少機率發生」的 equilibrium-selection distribution。 沒有這個分布，就不能把 best 與 worst equilibrium 按機率平均。

Uncertainty-averse planner

講義採 Gilboa–Schmeidler 式 maximin：不對均衡實現機率加限制，對每個 capital requirement 評估最差均衡，選擇使 worst outcome 最大者。得到的資本要求為 31%。

31% 不是一般意義下的唯一「最適資本比率」

它依賴極度保守的 equilibrium ambiguity 態度、模型中的福利組成、 資產與存款反應、以及未建模的均衡選擇。若 planner 有 equilibrium probabilities， 或對尾端結果的態度不同，答案也會不同。

14

如何解讀、使用與質疑這個模型？

最有價值的是量化 feedback mechanism；最需要謹慎的是工具排除限制、動態簡化與 equilibrium selection。

議題 模型的處理 閱讀時應問
CDS default measure 使用市場 CDS 建立 risk-neutral solvency measure。 風險溢酬與 physical default probability 的差異是否會影響 calibration？
Default-risk IV net charge-offs 與 alternative CMO specification。 資產損失是否也直接改變 branch quality、廣告、服務或 depositor information？
Rate IV Treasury shocks × bank-specific pass-through。 pass-through heterogeneity 是否與銀行風險、客群或服務趨勢相關？
Logit substitution 差異化銀行，但 ε 仍為 i.i.d. T1EV。 跨銀行替代是否主要由 shares 決定？關係型或地理 segmentation 是否更複雜？
Asset returns 每家銀行 R ∼ Normal(μ,σ)，且 shocks i.i.d. fat tails、common shocks、持續性與內生 risk choice 會如何改變壞均衡？
Bankruptcy dynamics stationary continuation，bankruptcy 後相同 capital structure。 resolution、fire sales、capital raising 與 franchise destruction 是否被低估？
Equilibrium selection 搜尋 fixed points；政策採 best/worst 與 maximin。 什麼新聞、coordination device 或政策承諾使經濟從一個均衡跳到另一個？
External validity 2002–2013 的大型美國商業銀行與 CD rates。 不同速度的數位提款、社群媒體資訊與 concentrated uninsured deposits 是否改變 γ 與動態？
最強貢獻

把 bank-run feedback 變成可量化的 equilibrium object

不是只展示 distressed banks 流失 deposits，而是估計 causal demand、反推 bank technology，並檢查完整 fixed points。

最脆弱環節

Outer identification 與 selection

壞均衡是否存在依賴 demand sensitivity 與 calibration；政策最適值又取決於如何對多個均衡賦予權重。

適合課堂討論的五個問題

  1. Charge-offs 對 uninsured depositors 是否真的只有透過 default probability 影響效用？
  2. 若 uninsured depositors 可以把資金轉往 Treasury funds，而不只是樣本內銀行，outside option 會怎麼改變 γ？
  3. 如果存款流失必須透過急售資產來應付，default feedback 是否會更強？
  4. 更高 deposit insurance 會穩定 funding，但會如何改變 bank risk-taking 與 FDIC cost？
  5. 若政策能協調 beliefs，是否可能用低於 31% 的 capital 避免壞均衡？

最後的記憶句

Deposit competition 決定銀行為 funding 支付多少；deposit beliefs 決定 funding 留不留下； funding 又決定銀行是否值得被股東救回。 當這三者形成夠強的正回饋，同一組 fundamentals 就不再對應唯一的 solvency outcome。

Dynamic Games of Network Competition

這份導讀把 87 頁投影片重排成一個故事：企業不是逐一選擇互不相干的市場， 而是在建造一張會改變需求、成本與競爭者反應的網路。航空公司的每一條航段、 Walmart 的每一家店，都會改變其他節點的價值；研究者真正要解的是 「如何從已實現的網路，反推出企業當初看見的跨市場與跨期誘因」。

原講義：Victor Aguirregabiria，87 頁 案例：Aguirregabiria–Ho 航空網路 · Holmes (2011) Walmart 重點：模型 timing · MPE · NPL · revealed preference · moment inequalities 開啟原始 PDF 更新：2026-08-07
Step 1 一個節點會影響別處

開一條航線或一家店，不只產生本地收入，也會改變轉機流量、運送成本與既有店銷售。

Step 2 今天會改變明天

進入成本與不可逆開店，使目前網路成為未來決策的 state，而不是可以每期重選的靜態選項。

Step 3 完整問題大到算不動

市場與地點一多，state/action space 呈指數成長；不能直接把 Bellman equation 硬解到底。

Step 4 用結構與選擇縮小問題

航空模型聚合 state 並迭代 CCP；Walmart 用局部替代政策形成 revealed-preference inequalities。

Step 5 反事實拆開經濟機制

估出 primitives 後逐一關掉需求、成本與策略效果，才知道 observed network 為何長成現在這樣。

一句話版本

網路模型的核心不是「企業進不進某一個市場」，而是「進入這個市場之後， 它在其他市場的需求、成本與策略位置會怎麼改變」。

Local choice

開航線、開店、增加一個產品或一個服務節點。

Network spillover

本地選擇改變其他市場的收益、成本或競爭者誘因。

Observed network

最後看見的網路，是許多 local margins 與未來選擇權共同作用的結果。

想像你是航空公司：多飛一段 A–B，不只多賣 A–B 的直飛票；它也讓 C–A–B 這條轉機路徑成為可能。再想像你是 Walmart：在既有店旁邊開新店會搶走舊店顧客， 卻也可能讓配送、庫存與區域管理更便宜。這兩個例子的共通點，是同一家公司的節點彼此相連。

多家公司策略互動。除了網路 spillover，還要預測競爭者未來的進入與退出，因此是 dynamic game。

為什麼「同一家公司」也會有 network externality？

Externality 在這裡不一定表示影響別家公司。它是說，一個 local decision 的 payoff 不能只由該地點本身決定。若在節點 m 的行動會改變節點 m′ 的 profit，兩個局部問題就被連起來。寫成最簡單的形式：

πim = πim(aim, ai,-m, a-i, state)

ai,-m 是同一家企業在其他節點的選擇； a-i 是競爭者的選擇。前者帶來 own-network spillover， 後者帶來 strategic interaction。

Network effect 不等於 network industry

這裡未必是典型「使用者越多，平台越有價值」的直接網路效果。更廣義地說，只要不同 local operations 的 payoff 相互依存，就已經形成 network competition 問題。

航空故事：消費者喜歡直飛，航空公司為何仍然 hubbing？

先把 hub-and-spoke 背後的三股力量分開。 slides 8–23

Point-to-point (P2P) 讓城市對直接相連；hub-and-spoke (H&S) 則把流量集中到少數 hub，再由 hub 接到 spokes。投影片用兩個 concentration ratios 描述航空公司有多「hub-oriented」：

CRi1 = Mi1 / Mi
CRi2 = (Mi1 + Mi2) / Mi

Mi 是航空公司 i 經營的 nonstop city-pairs 數；Mi1、Mi2 是連到其最大、第二大機場的航段數。CR2 越高，表示很多航段集中在兩個核心機場。

需求力量：偏向 P2P

旅客通常討厭轉機。其他條件不變，H&S 增加中停與時間成本，對 consumer welfare 不利。

成本力量：可能偏向 H&S

同一機場的登機門、人員、維修與地勤可共同使用。hub 規模越大，邊際或固定營運成本可能越低。

策略力量：偏向 H&S

某一航段不只賺 local passengers，也支撐 connecting passengers，因此 incumbent 可能願意守住看似虧損的市場，嚇阻 entrant。

Entry deterrence 的故事

  1. 既有航空公司用 A 當 hub，經營 A–B 與 A–C。
  2. 潛在進入者想進 A–B，而且其 local cost 甚至低於 incumbent。
  3. 若只看 A–B 本地需求，這個市場只能容納一家；照理 entrant 應該取代 incumbent。
  4. 但 incumbent 的 A–B 還是 C–A–B 轉機路線的一段。退出 A–B 會一起失去 connecting profit。
  5. 因此 incumbent 即使在 A–B 的 standalone profit 為負，也可能選擇留下。
  6. entrant 預見進入後不會逼退 incumbent，雙方競爭下自己無利可圖，於是乾脆不進。
這裡真正的 commitment 是什麼？

hub network 讓 incumbent 對某個 local segment 有「超越本地市場」的價值，因此它更可信地承諾會迎戰。 不是口頭說要打價格戰，而是網路結構改變了留下來的 payoff。

為何不能把 hub size 當外生控制變數就結束？

若研究 merger，合併後航空公司會重新安排 hub、進出航線；hub size 本身就是最適決策的結果。 把它固定，等於禁止模型預測 merger 最重要的中期調整。因此需要 endogenous network model。

讀懂下標，就讀懂了動態模型。 slides 24–26

符號定義在故事裡的意思
i = 1,…,N航空公司；基準設定 N = 11策略玩家
c = 1,…,C城市；C = 55網路端點

一季的事件順序

  1. 進入本季：既有 network xt 已知。
  2. 價格競爭：目前可提供各 route 的航空公司進行 static Bertrand competition，形成價格、需求與 variable profits。
  3. 網路決策：航空公司觀察 payoff-relevant state 與 private shocks，選 at。
  4. 下季：xt+1=at，今天的 action 變成明天的 state。
為什麼要放 time-to-build？

航線配置不能瞬間隨價格結果任意切換；班表、登機門、人員與設備需要先安排。形式上， at=xt+1 也讓「今天的選擇影響明天」 清楚進入 Bellman recursion。

city-pair、segment、route 與 product 為什麼不能混用？

A–B city-pair 是 local market；航空公司若在此 nonstop，便提供一個 segment。 但消費者的 route 可能是 C–A–B，因此由 C–A 與 A–B 兩段組成。需求定義在 route-airline product，而 network decision 定義在 nonstop city-pair。正因為一個 segment 可被多條 route 使用，才產生跨市場 network effect。

Profit function 逐項拆解：哪裡把網路接起來？

一條式子同時包含 product market 與 network investment。 slides 27–28

Πit = Σr∈L(xit) (pirt−cirt)qirt − Σm=1M aimt[FCimt+(1−ximt)ECimt]

Current variable profit

(p−c)q 對所有可由目前網路 xit 提供的 routes 加總。今天的 network 決定今天有哪些產品能賣。

Fixed operating cost

若 aimt=1，公司選擇下季維持或開始該 segment， 因而支付 FCimt。

Sunk entry cost

只有 a=1 且 x=0 時， (1−x)EC 才出現。維持既有線不需重付 entry cost。

為什麼 sunk entry cost 會製造 persistence？

已在市場內的公司比較「捨不得退」，因為退掉後若想回來，未來必須再付 EC。因此同一個當期 variable profit，對 incumbent 與 outsider 會導致不同選擇。這種 state dependence 是動態模型的核心：

Cost(active next period) = FCimt + 1{ximt=0}·ECimt

Hub effects 如何進入成本？

FCimt = γ1FC + γ2FCHUBimt + γ3FCDISTm + airline FE + endpoint FE
ECimt = η1EC + η2ECHUBimt + η3ECDISTm + airline FE + endpoint FE

若 γ2 或 η2 為負， hub 越大，營運或進入該 city-pair 越便宜。由於增加某個 segment 也可能增加機場 hub size， 一個 market 的 entry/exit 會改變其他 markets 的成本，網路就被內生地接起來。

重要：profit equation 本身還不是 value function

Πit 是一期 flow payoff。forward-looking 公司比較的是 「今天 flow payoff + 未來 network 的 continuation value」。只看本期 profit 會漏掉 entry cost、未來轉機收入與競爭者反應所形成的 option value。

從 profit 到 dynamic game：為什麼需要 MPE？

今天的航線同時改變自己與對手明天的 incentives。 slides 29–30

如果只有一家航空公司，解的是 dynamic program；有多家公司，而且每家公司知道自己的行動會改變 別人未來的選擇，便成為 dynamic game。對公司 i，概念性的 Bellman problem 是：

Vi(st,εit) = maxait { Πi(st,ait,a−i,t,εit) + βE[Vi(st+1,εi,t+1) | st,at] }

Markov strategy 的限制

σi(xt,zt,εit)

策略只依賴目前 payoff-relevant state，不依賴整段歷史本身。過去若重要，必須已濃縮在 xt、其他 observable states zt 與 private payoff shock εit 中。

為什麼需要 Markov assumption？

若策略可依賴任意歷史，兩個目前網路完全相同的產業可能因為十年前的事件而採不同策略， state 無法有限維度化，估計也無從累積相似觀察。Markov restriction 讓 current state 成為足夠的歷史摘要。

MPE 的 fixed-point 邏輯

一組策略 {σi}i=1N 是 Markov perfect equilibrium，若在每一個可能 state，每家公司把其他公司的策略當成給定時， 自己的策略都最大化其 value。換句話說：

Belief

我相信競爭者會依照目前 state 採某些 entry/exit probabilities。

Best response

在這些 beliefs 下，我計算最適的 own policy。

Consistency

所有人的 best responses 恰好等於一開始拿來預測的 policies。

為什麼完整解法會爆炸？

每家航空公司在 1,485 個 city-pairs 都有 0/1 狀態。若用模型設定的 11 家公司， 已有 211×1,485≈104,917 種產業網路； p.30 按實證規模報告約 1010,000。真正的問題不是 Bellman equation 不會寫，而是根本無法列舉 state、儲存 value 或計算每個 transition。

捷徑一：把航空公司拆成很多地方經理

分權本身不是關鍵，地方經理最大化什麼才是。 slide 31

作者把每家航空公司的 network choice 拆成 M 個 local managers。 經理 (i,m) 只選該 city-pair 下季是否活躍： aimt∈{0,1}。

ait∈{0,1}M（2M 種 joint actions）  →  M 個問題，各自只有 aimt∈{0,1}
Πimt = Rimt − aimt[FCimt +(1−ximt)ECimt]

其中 Rimt 不是只有 A–B 直飛產品的 profit， 而是所有使用 segment m 的 routes之 variable profits 加總。 所以 A–B 經理會把 C–A–B 的收益也算進來。

用 A–B segment 把 objective 說成一個故事

  1. A–B manager 先計算 A–B 直飛產品的 variable profit。
  2. 再加入所有把 A–B 當作一段的 connecting routes，例如 C–A–B、D–A–B。
  3. 若下季要 active，就扣掉 fixed cost；若本期原本 inactive，還要額外扣 sunk entry cost。
  4. 因此即使 A–B 的 standalone profit 為負，只要它支撐的 connecting profits 足夠大，manager 仍可能留下；這正是 entry deterrence 得以保留的原因。

保留下來的 network effect

local manager 仍內部化該 segment 對所有 connecting routes 的影響，因此不會把 entry deterrence 故事切掉。

被限制的 coordination

經理不一定完整內部化其 action 對其他 segment 經理未來政策、全公司資源配置或更高階互補性的影響。

「分權 without loss of generality」只說了一半

任一 centralized optimum 理論上可透過適當 transfer prices 分散執行，因此「由地方經理下決策」 本身可以只是組織語言。但一旦指定地方經理只最大化上面這個 Πimt，就成為實質限制。估計可行性正是來自這個 objective restriction。

可等價重寫的部分

如果總部能任意設計 state-dependent transfer prices，就能把每條 segment 對全公司其他部門的 marginal contribution 記到 local manager 帳上，使 decentralized choices 實作 centralized optimum。

真正需要相信的部分

論文沒有保留任意複雜的 transfer-price function，而是指定一個簡單 local objective。 它必須足以近似總部真正關心的 network contribution，才不會扭曲 entry/exit incentives。

Local payoffs 不是一套可直接相加的公司會計

同一條 connecting route 可能同時使用兩個 segments，因此其 profit 會出現在不只一位 manager 的 Rimt 中。這不妨礙每位 manager 衡量自己的 segment contribution， 但表示把所有 local objectives 相加不一定等於 airline total profit；這是行為／組織限制，不是 accounting identity。

把它想成 scope 的選擇

原本一個玩家一次選 1,485 維的 action vector；現在變成 1,485 個 binary local problems。 這還沒有解決 state 太大的問題，但先把「聯合 action space」拆開了。

捷徑二：inclusive state 如何把整張網路壓縮？

讓地方經理只記住對自己 payoff 最重要的摘要。 slides 32–33

ximt* = (ximt, Rimt, HUBimt)

地方經理不再把整個 xt 當 state，而只記三件事： 自己目前是否 active、所有用到自己 segment 的 route profits、兩端機場的 hub 規模。 這三個量被當成完整產業網路對此 local problem 的 payoff-relevant summary。

Inclusive-state 成分它濃縮的資訊manager 心中的問題
ximtincumbent status 與 sunk-cost history我已經在市場內，還是進入時必須多付 EC？
Rimtlocal demand、價格、競爭者與 connecting routes 共同形成的 current variable profit這條 segment 現在總共支撐多少收益？
HUBimt兩端機場的 network scale、scope economies 與 strategic embeddedness這條 segment 位於多核心的 network 位置？
Pr(xim,t+1* | ximt*,aimt,xt,zt) = Pr(xim,t+1* | ximt*,aimt)

這個 controlled first-order Markov assumption 說了什麼？

一旦知道 local summary x* 與自己的 action， 整張產業網路或更早歷史不再提供預測下一期 local summary 的額外資訊。這叫做 closure：地方經理的問題可在小 state space 內自行遞迴。

Full world

競爭者在各地的網路、需求與成本共同決定明天。

Compression

把這些資訊濃縮成本地 revenue 與 hub size。

Local recursion

只用 (x*,a) 的 transition 計算 continuation value。

如果這個 conditional independence 成立，local Bellman problem 就能在小 state space 內封閉：

Vim(x*) = maxa∈{0,1} { R − a[FC+(1−x)EC] + βE[Vim(x*′) | x*,a] }

右邊只需要 local flow payoff 與 Pr(x*′|x*,a)，不用再為完整 (xt,zt) 建立 value table。

這不是 BLP 裡的 log-sum inclusive value

名字相似，但這裡的 inclusive values 是 dynamic state aggregation： 用少數 payoff summaries 近似整張 network 的作用。它不是把消費者選項效用取 log Σ exp(·) 的 nested-logit inclusive value。

降維沒有把競爭者或 dynamics 當成外生

rivals 的網路仍會影響當期 R、HUB，也會透過 Pr(x*′|x*,a) 影響 continuation value。作者做的是把對手的詳細航網壓縮成 dashboard 與其 transition，而不是假設對手不存在。

「可以算」不等於「aggregation 已被證明正確」

Bellman contraction 能說什麼？

給定 transition、對手策略且 β<1 時，local Bellman operator 通常可讓 reduced model 的 value iteration 收斂。

它不能說什麼？

它不能證明 (x,R,HUB) 真的是 full network 的 sufficient statistic。 收斂只代表 reduced model 解得穩，不代表 reduction 沒有漏資訊。

一個會讓 aggregation 失敗的反例

兩個 A–B markets 今天可能有完全相同的 x、R 與 HUB；但第一個市場的 rival 正在鄰近機場建立大型 hub，第二個 rival 的航網則在遠端。 若這些 full-network differences 仍能預測明年的 entry threat，則 Pr(x*′|x*,a,xt,zt) 不會等於 Pr(x*′|x*,a)，inclusive state 就不充分。

代價：可能遺漏具有預測力的全局資訊

兩個產業網路可能有相同的 local revenue 與 hub size，卻因競爭者在遠端的佈局不同而有不同未來。 若如此，Markov aggregation 失敗。實證上應檢查在控制 x* 後， 其他 full-network summaries 是否仍能預測 x*′ 或 entry choices。

降維後，一個 MPE 可用每個地方經理的 conditional choice probability 描述：

Pim(ximt*) = Pr(aimt=1 | ximt*)

equilibrium 存在，但通常可能多重。降維讓每個 equilibrium 比較容易表示與計算，並沒有自動完成 equilibrium selection；不同起始 CCP 可能指向不同 fixed points。這一點會在 NPL 與 counterfactuals 再出現。

兩層降維的交換條件

第一層以「local objective 足以代表 segment 對公司的貢獻」換取小 action space；第二層以 「(x,R,HUB) 足以預測 local future」換取小 state space。 可計算性不是免費得到，而是用 organizational restriction 與 Markov-sufficiency restriction 換來。

NPL 到底怎麼跑？為何它比每次重解完整賽局便宜？

把 equilibrium fixed point 拆成「估參數」與「更新策略」兩個迴圈。

動態賽局最麻煩的地方，是 likelihood 中每試一組參數 θ，理論上都要重新解一個 MPE。Nested Pseudo Likelihood 的主意是：先暫時把競爭者的 CCPs 當成已知，再估 best response；接著才更新 CCPs。

故事版：先問「大家看起來怎麼飛」，再問「什麼成本會讓理性航空公司這樣飛」

reduced-form choice model 先忠實描述 observed entry/continuation patterns，給我們一張暫時的 competitor playbook。結構模型再把這張 playbook 放進未來 payoff，反推出能合理化這些選擇的 fixed cost、entry cost 與 payoff-shock scale。最後更新 playbook，直到「預期別人怎麼做」與 「模型說大家最適時會怎麼做」相符。

一個 action 的價值：今天付建置成本，換取明天的 option value

local manager 選 aimt∈{0,1}，其中 1 表示下一期維持／建立此 segment。 因為有一季 time-to-build，今天無論選哪個 action，current network 與 R* 都已經給定；今天的 revenue 因而在兩個 actions 的差分中抵消。 選 active 相對 inactive 的 deterministic value difference 是：

Δvim(w;θ,P) = −FCim−(1−xim)ECim +βΔEVimP(w)

incumbent 已經 active，選擇下期繼續飛只付 fixed cost；outsider 若選擇下期進入，還要多付一次 sunk entry cost。 最後一項是 option value：今日建好 segment 會改變明日 network、profits 與之後的選擇機會。 R* 並沒有消失：它是 state，透過對未來 revenue 的預測進入 ΔEV，而不是被錯當成今天 action 立刻創造的收入。 給定 private payoff shock 為 logistic，其 conditional choice probability 是：

Pim(w)=Λ(Δvim(w;θ,P)/σε)

P 同時出現在右側，是因為 continuation value 要預測 rivals 未來的 actions； rivals 怎麼做又由它們的 CCPs 決定。這正是 dynamic game 的 equilibrium feedback。

NPL 的 benefit

  • 不用在 optimizer 每試一個 θ 時，從零開始解完整 MPE。
  • CCPs 把其他玩家策略對 continuation value 的影響濃縮成可估的 objects。
  • 能利用 local-choice likelihood 與 large panel of market-manager observations。

NPL 沒有免費解決的問題

  • Ψ 不保證是 global contraction。
  • 多重 equilibria 時，不同起點可能收斂到不同 fixed points。
  • generated profits、初始 CCP 或 simulated transition 的誤差會傳進 continuation values。
實務上怎麼判斷結果不是初始化碰巧造成？

用多組初始 CCPs 重跑、記錄收斂／循環情況，並比較最後的 pseudo-likelihood。原文以多個起點搜尋， 保留 likelihood 較高的 converged solution。這能揭露 local fixed points，但不能把 equilibrium selection 變成已知；counterfactual 仍需說明沿用哪個 equilibrium branch。

「重複就一定收斂」不是定理

Bellman operator 在標準 discounting 下常是 contraction，但 NPL 更新的是 equilibrium policy map，不是單一代理人的 Bellman value operator。 strategic feedback 可能使其不收斂、循環或只局部收斂。因此要檢查不同起點、收斂準則， 並誠實處理 equilibrium selection。

為何 entry-cost channel 最大？

Holmes 真正要回答的四個問題

1. 為何由內向外、連續擴張？

2. Cannibalization 有多大？

新店 sales 中，多少是真正從 outside retailers 搶來，多少只是從既有 Walmart 移轉？

3. Density benefit 值多少？

stores 靠近 distribution centers 帶來的配送、快速補貨、庫存與區域管理價值有多大？

4. 限制 store density 的代價？

zoning 或 antitrust divestiture 若拆散 network，Walmart 的 cost side 會付出多少代價？

這篇不是完整的 competition／welfare paper

Holmes 不明確建模 Kmart locations、rival entry 或 preemption，也不把估出的 firm-cost effect 直接等同 consumer welfare。它專注 own-store cannibalization、density economies 與不可逆的 opening sequence； competitor-driven clustering 若重要，可能被 τ 吸收。

識別的核心是一個 opportunity-cost argument

Moment inequalities：從「Walmart 沒有後悔」推導參數界線

這是 revealed preference 的動態版本。 slides 78–81

Step 1：optimality implication

若 observed opening sequence σobs 最適， 對任何可行 alternative sequence σ 都有：

Vt(σobs) − Vt(σ) ≥ 0

這句話不要求研究者知道 Walmart 的 value 有多大，只要求 observed choice 不比一個明確可行的 counterfactual choice 差。

Step 2：把 value difference 分成已知部分與待估成本

Vt(σobs) − Vt(σ) = yt(σ) − xt(σ)θ
  • yt(σ)：兩條 policies 的 discounted variable-profit difference。 demand 與 accounting steps 已讓它可計算。
  • xt(σ)：兩條 policies 在 DC distance、人口密度與平方項上的 discounted exposure difference。
  • θ：distance cost 與 location fixed-cost coefficients。

因 fixed cost 對參數是線性的，每個 deviation 都在 θ 空間切出一個 half-space：

yt(σ) − xt(σ)θ ≥ 0

Step 3：乘上 nonnegative instruments，再取期望

mk,σ(θ0) = E[zkt{yt(σ)−xt(σ)θ0}] ≥ 0,   zkt≥0

為何要求 z≥0？因為乘以負數會翻轉 inequality。 predetermined instruments 可讓不同 state 或年份的 revealed-preference comparisons 得到不同權重，產生更多辨認方向。

為何不要求 522,967 條 individual inequalities 每條都成立？

Store sales、wages、rents 與 first-stage demand 都有 measurement error；若逐條硬套 restriction， 一個極端負誤差就可能主宰整個 identified set。Holmes 以 12 個經濟意義清楚的 deviation groups 建立非負 indicators／weights，先在組內平均，使 errors 有機會消去，再形成 moment inequalities。

Step 4：樣本中只懲罰 violated inequalities

Θ̂I = set of arg minθ Σk,σ min{0,m̂k,σ(θ)}2

若某個 sample moment 為正，它符合 model restriction，不需懲罰；若為負，代表該參數使 alternative 看起來比 observed policy 更好，違反 optimality，因此平方負部。所有不等式的交集通常是一個 identified set，而不是唯一點。

為什麼是 partial identification？

一個 observed choice 只告訴我們「它至少不差於 alternative」，沒有告訴價值剛好相等。 每個 inequality 只排除一側參數；除非 comparisons 極其豐富，通常會留下整個參數區間。 這不是 estimator 失敗，而是資料與 optimality restrictions 真正提供的資訊量。

把一條 inequality 畫成直覺

假設 swap policy 會讓 variable profit 多 10，但配送 miles 也多 4。observed policy 較好要求 0−10 + 4τ ≥ 0，亦即 τ≥2.5。 這條 comparison 給 τ 一個下界。另一個反方向 deviation 可能給上界； 多個 bounds 的交集形成 identified interval。

為何交換兩家店的開店年份，是特別有力的 deviation？

若 observed sequence 是店 1 在 1962 開、店 2 在 1964 開，deviation 只把兩者年份交換， 其他每家店與每個 opening year 全部不變。

1962 先開遠店 j′，1964 才開近店 j；兩年間的 Walmart network 較分散。

Pairwise swap 有四個優點

1. 保持 expansion scale

在兩個被交換年份之間，兩條 policies 都恰有其中一家店營業；每年總開店數不變，不需建模 aggregate expansion speed。

2. 接近 observed policy

不是比較完全不同的幻想版 Walmart，只做局部排序變動，對未建模誤差較穩健。

3. 專門移動目標 state

可挑會明確增加／降低 store density 或 population density 的 pairs，讓 inequality 對 τ 或 ω 更敏感。

4. 大量 common terms 抵消

較晚日期之後 store set 完全相同，長期 profits 抵消；每期店數相同也讓 constant fixed-cost term ω0 抵消。

這像一個由企業自己做出的 matched comparison

作者不問「為何開 j 而永遠不開 j′」，而問「為何 j 要比 j′ 早兩年」。 這個較窄的排序問題，正好揭露 Walmart 對早期 density benefits 與 cannibalization costs 的權衡。

局部 deviations 的 tradeoff

它們只提供 global optimality 的必要條件，不證明 observed sequence 在所有可能 policies 中最優。 只要所選 swaps 沒有足夠改變某一 state exposure，那個參數就可能界得很寬。 另一方面，若真實決策受未建模的 store-specific constraint 影響，即使小 swap 也可能不是可行替代方案。

Walmart 結果：每 mile 的成本為何不只是卡車油錢？

估計的 τ 捕捉整套「靠得近」的組織價值。 slides 85–87

Baseline estimate

τ = $3,500 per mile, store, year。 若 5,000 家 Walmart stores 每家都離 distribution center 遠 100 miles， 年成本會增加近 20 億美元： 5,000 × 100 × $3,500 = $1.75bn，約為投影片所稱「almost $2 billion」。

為何不是純卡車成本？

這個估計約是單純 trucking-cost saving 的四倍。Holmes 因此把超出的部分解讀為：

  • Just-in-time inventory flexibility：離 DC 近，可更快補貨並回應 local demand shocks，減少缺貨與過度庫存。
  • Managerial economies of density：區域管理、人員支援與 labor relocation 更容易。
  • 其他未單獨建模的 logistics complementarities：τ 是 reduced-form cost index，不是只有每 mile 的卡車帳單。
另一個角度的 validation：distribution-center timing

Baseline 固定 DC opening dates、交換 store dates。作者另外反過來固定 stores，問 DC 為何在實際年份開， 以「開早一年不值得、實際年份值得」的 inequalities 粗略倒推 τ≈$3,100。 它與主方法的約 $3,500 接近；兩種 comparisons 依賴不同 margin，因而是有用的 external consistency check。

政策含義

若 zoning、divestiture 或其他政策大幅限制 Walmart store density，成本可能顯著上升。 但 welfare 判斷不能停在 Walmart 成本：還要計入消費者可及性、local competitors、勞動市場、 market power 與城市外部性。這篇估計主要提供企業 cost side 的一塊。

最關鍵的 omitted mechanism：preemption

若 Walmart 早期沿某路線密集開店，是為了搶先封鎖 Kmart 或未來 entrants， observed willingness to cluster 不全是配送 savings。模型忽略明確的 competitor locations 與 preemption，可能讓 τ 吸收部分策略價值。投影片也把這列為重要限制。
